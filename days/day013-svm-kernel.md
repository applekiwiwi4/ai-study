## 1. 한 줄 요약
**SVM(Support Vector Machine)** 은 두 그룹 사이에 **가장 넓은 길(마진)** 을 내는 경계선을 찾는 분류 모델입니다. 경계를 정하는 데 실제로 쓰이는 것은 길 가장자리에 닿아 있는 몇 개의 점, 즉 **서포트 벡터**뿐입니다. 직선으로 나눌 수 없는 데이터는 **커널(Kernel)** 이라는 기법으로 데이터를 더 높은 차원으로 "들어 올린 것처럼" 계산해서, 원래 공간에서는 곡선인 경계를 만듭니다. 딥러닝 이전(2000년대)에는 이미지·문서 분류에서 가장 강력한 모델이었고, 지금도 데이터가 적고 특성이 많은 문제에서 많이 쓰입니다.

```
        x₂                                       경계선 후보는 무수히 많지만
         │   ○    ○                               SVM은 "양쪽 점과의 거리(마진)"가
         │ ○   ○      ╲   ╲   ╲                    가장 넓은 선 하나를 고른다
         │    ⓞ  ○     ╲   ╲   ╲    ●
         │  ○    ⓞ      ╲   ╲   ╲  ●   ●          ⓞ ⓢ = 서포트 벡터
         │               ╲   ╲   ⓢ    ●              (길 가장자리에 닿은 점)
         │                ╲   ╲ ⓢ  ●    ●
         │                 ╲   ╲   ●  ●           ╲ (가운데) = 결정 경계
         └──────────────────────────────── x₁     ╲ (양옆)  = 마진 경계
                      ←─ 마진 ─→
```

## 2. 핵심 용어
| 용어 | 뜻 | 예시 |
|---|---|---|
| 초평면 (Hyperplane) | 공간을 둘로 나누는 경계. 2차원에서는 직선, 3차원에서는 평면 | `w·x + b = 0` |
| 마진 (Margin) | 결정 경계와 가장 가까운 점 사이의 거리(길의 폭) | 넓을수록 일반화가 좋음 |
| 서포트 벡터 (Support Vector) | 마진 경계 위나 안쪽에 있어서 경계 위치를 결정하는 점 | 전체 중 일부만 |
| 하드 마진 (Hard Margin) | 오분류를 하나도 허용하지 않는 SVM | 노이즈에 매우 약함 |
| 소프트 마진 (Soft Margin) | 일부 점이 마진 안이나 반대편에 들어오는 것을 허용 | 실무 표준 |
| C (규제 파라미터) | 마진 침범을 얼마나 엄하게 벌줄지. 크면 엄격(좁은 길), 작으면 관대(넓은 길) | `C=1.0` |
| 힌지 손실 (Hinge Loss) | `max(0, 1 - y·f(x))`. 마진 밖에서 맞히면 0, 아니면 벌점 | |
| 커널 (Kernel) | 두 점이 "고차원에서 얼마나 비슷한가"를 바로 계산하는 함수 | 선형, 다항, RBF |
| 커널 트릭 (Kernel Trick) | 실제로 고차원으로 변환하지 않고 커널 값만으로 계산하는 기법 | |
| RBF 커널 | `exp(-γ‖x - x'‖²)`. 가까울수록 1, 멀수록 0. 가장 많이 쓰는 커널 | `kernel="rbf"` |
| γ (gamma) | RBF 커널에서 점 하나의 영향 범위. 크면 좁고 뾰족, 작으면 넓고 완만 | `gamma="scale"` |
| SVR | SVM을 회귀(숫자 예측)에 쓰는 버전 | |

## 3. 개념과 작동 원리

### 3-1. 왜 "가장 넓은 길"인가?
두 그룹을 나누는 직선은 무수히 많습니다. 어떤 선이 가장 좋을까요?
```
   선 A (한쪽에 바짝 붙음)            선 B (가운데, 마진 최대)
   ○ ○   │●  ●                       ○ ○    ╎   ●  ●
   ○  ○  │ ●   ●                     ○  ○   ╎    ●   ●
     ○ ○ │●  ●                         ○ ○  ╎   ●  ●
   새 점 ●이 조금만 왼쪽에 와도        새 점이 조금 흔들려도
   ○로 잘못 분류됨                     여유가 있어 올바르게 분류
```
> 훈련 데이터를 똑같이 100% 맞히더라도, **양쪽에 여유 공간이 가장 넓은 경계**가 처음 보는 데이터에도 강합니다. 이것이 SVM의 핵심 아이디어인 **마진 최대화**입니다.

### 3-2. 수식으로 보는 마진
결정 경계는 Day 010의 로지스틱 회귀처럼 `f(x) = w·x + b`입니다. SVM은 다음 규칙을 둡니다.
```
 정답 y = +1 인 점:  w·x + b ≥ +1      (마진 경계 위 또는 바깥)
 정답 y = -1 인 점:  w·x + b ≤ -1
 → 합쳐서:  y·(w·x + b) ≥ 1

 두 마진 경계(f = +1, f = -1) 사이 거리 = 2 / ‖w‖

 마진을 최대화 = ‖w‖를 최소화
 목표: minimize ½‖w‖²   조건: 모든 점에서 y·(w·x + b) ≥ 1
```
```
          f(x) = -1    f(x) = 0    f(x) = +1
              ╎           │           ╎
     ○   ○    ╎           │           ╎    ●   ●
        ○   ⓞ ╎           │           ╎ ⓢ    ●
     ○        ╎           │           ╎      ●
              ╎←── 1/‖w‖ ─┼─ 1/‖w‖ ──→╎
              ╎←──── 마진 = 2/‖w‖ ────→╎
```

### 3-3. 소프트 마진과 C — 노이즈를 얼마나 봐줄까
실제 데이터에는 반대편에 섞인 점(노이즈)이 있어서 완벽한 직선이 없을 때가 많습니다. 그래서 위반을 허용하되 **벌점**을 줍니다.
```
 목표: minimize  ½‖w‖²  +  C · Σ 힌지손실ᵢ
                 ↑ 넓은 길       ↑ 규칙 위반 벌점

 힌지 손실 = max(0, 1 - y·f(x))
   y·f(x) ≥ 1   (마진 밖에서 정답)     → 손실 0
   0 < y·f(x) < 1 (정답이지만 마진 안)  → 작은 손실
   y·f(x) ≤ 0   (오분류)              → 큰 손실
```
| C 값 | 의미 | 길 폭 | 위험 |
|---|---|---|---|
| 작음 (0.01) | 위반을 너그럽게 봐줌 | 넓음 | 과소적합 (너무 단순) |
| 큼 (100) | 위반을 엄하게 벌줌 | 좁음 | 과적합 (노이즈까지 맞춤) |

> Day 005의 규제와 같은 원리입니다. **C는 규제 강도의 역수**라고 생각하면 됩니다 (C가 작을수록 규제가 강함).

### 3-4. 커널 트릭 — 직선으로 못 나누면 차원을 올린다
원 안쪽(○)과 바깥(●)으로 나뉜 데이터는 직선 하나로 절대 나눌 수 없습니다. 그런데 새 특성 `z = x₁² + x₂²`(원점에서의 거리²)를 추가하면 어떻게 될까요?
```
 원래 2차원 (직선 불가)                     z = x₁² + x₂² 를 추가한 3차원
     x₂                                     z
      │   ●  ●  ●                           │ ●  ●     ●   ●  ●       ← 바깥 점은 z가 큼
      │ ●   ○ ○   ●                         │    ●   ●    ●
      │●  ○  ○  ○  ●                         │━━━━━━━━━━━━━━━━━━━━━━   ← 평평한 평면으로 나뉨!
      │ ●   ○ ○   ●                         │  ○ ○  ○ ○  ○  ○         ← 안쪽 점은 z가 작음
      │   ●  ●  ●                           └─────────────────── x₁, x₂
      └────────────── x₁
             ↓ 3차원의 평면을 다시 2차원으로 내려 보면 → 원 모양 경계
```
- 이렇게 특성을 직접 늘리면 계산이 무거워집니다. 차수가 높거나 특성이 많으면 새 특성 수가 폭발적으로 늘어납니다.
- SVM의 계산은 점 두 개의 **내적(x·x')** 만 필요하다는 성질이 있습니다 (Day 007). 그래서 "고차원으로 변환한 뒤의 내적"을 **원래 공간에서 바로 계산하는 함수(커널)** 로 바꿔치기하면 변환 없이 같은 효과를 얻습니다. 이것이 **커널 트릭**입니다.

| 커널 | 식 | 경계 모양 | 언제 |
|---|---|---|---|
| 선형 (linear) | `x·x'` | 직선/평면 | 특성이 매우 많을 때 (문서 분류 등) |
| 다항 (poly) | `(γ·x·x' + r)ᵈ` | d차 곡선 | 특성 간 곱셈 관계가 있을 때 |
| RBF (가우시안) | `exp(-γ‖x - x'‖²)` | 어떤 모양이든 가능 | **기본 선택** |
| 시그모이드 | `tanh(γ·x·x' + r)` | 신경망과 비슷 | 드묾 |

### 3-5. RBF 커널과 γ — "가까운 점끼리 비슷하다"
RBF 커널은 두 점이 가까우면 1, 멀면 0에 가까운 값을 줍니다. 각 서포트 벡터 주위에 **언덕**을 하나씩 세우고, 그 언덕들을 더해 경계를 만든다고 상상하면 됩니다.
```
 γ 작음 (0.1)                γ 적당 (1)                  γ 큼 (100)
   넓고 완만한 언덕            적당한 언덕                  좁고 뾰족한 언덕
     ╭─────────╮               ╭───╮ ╭───╮                 ╷ ╷ ╷╷ ╷ ╷
   ╭─╯         ╰─╮           ╭─╯   ╰─╯   ╰─╮               │││││││││
 ──╯             ╰──       ──╯             ╰──           ──┴┴┴┴┴┴┴┴┴──
 경계가 너무 단순             적당한 곡선                   점마다 섬 하나씩
 → 과소적합                                               → 과적합
```
> **C와 γ를 함께** 조정하는 것이 RBF SVM 튜닝의 핵심입니다. 보통 격자 탐색(Grid Search)으로 여러 조합을 시험합니다.

### 3-6. SVM 사용 시 주의점
| 주의점 | 이유 | 대처 |
|---|---|---|
| **특성 스케일링 필수** | 거리·내적 기반이라 범위가 큰 특성(예: mm 단위 vs 0~1 비율)이 결과를 지배 | `StandardScaler` (Day 002) |

| 확률 출력이 기본이 아님 | SVM은 "경계에서 얼마나 떨어졌나"만 계산 | `probability=True` (느려짐) |
| 다중 분류 | 본래 이진 분류용 | 내부에서 1:1 조합으로 자동 처리 |

## 4. 구조 — SVM의 예측 방식
```
 학습이 끝나면 남는 것: 서포트 벡터 s₁, s₂, ..., sₖ 와 각각의 가중치 αᵢ, 그리고 b

 새 점 x 예측:
   f(x) = Σᵢ αᵢ · yᵢ · K(sᵢ, x) + b         ← 서포트 벡터와의 "커널 유사도"를 가중합
   f(x) > 0 → 클래스 +1,  f(x) < 0 → 클래스 -1
   |f(x)|  = 경계에서 얼마나 확실하게 떨어져 있는가

   새 점 ──┬── K(s₁, x) × α₁y₁ ──╮
           ├── K(s₂, x) × α₂y₂ ──┼──▶ Σ + b ──▶ 부호 ──▶ 클래스
           └── K(sₖ, x) × αₖyₖ ──╯
   (마진 밖의 나머지 점들은 αᵢ = 0 → 예측에 아무 영향 없음)
```
> 서포트 벡터만 기억하면 되므로 모델이 가볍고, 경계에서 먼 점이 바뀌거나 추가돼도 경계는 그대로입니다.

## 6. 코드로 보기

### 6-1. 선형 SVM — 서포트 벡터와 마진 확인
```python
import numpy as np
from sklearn.svm import SVC

rng = np.random.default_rng(3)
X = np.vstack([rng.normal([2, 2], 0.6, (20, 2)),       # 클래스 0 (○)
               rng.normal([5, 5], 0.6, (20, 2))])      # 클래스 1 (●)
y = np.array([0] * 20 + [1] * 20)

svm = SVC(kernel="linear", C=1.0).fit(X, y)
w, b = svm.coef_[0], svm.intercept_[0]
print(f"경계: {w[0]:.2f}·x₁ + {w[1]:.2f}·x₂ {b:+.2f} = 0")
print(f"마진 폭 = 2/‖w‖ = {2 / np.linalg.norm(w):.2f}")
print(f"전체 {len(X)}개 중 서포트 벡터 {len(svm.support_)}개")

# 글자 그림: ○●=일반 점, ⓞⓢ=서포트 벡터, ╲=결정 경계(f≈0), ·=마진 경계(f≈±1)
H, W = 14, 40
grid = [[" "] * W for _ in range(H)]
for r in range(H):
    for c in range(W):
        x1, x2 = c / (W - 1) * 7, (1 - r / (H - 1)) * 7
        f = w[0] * x1 + w[1] * x2 + b
        if abs(f) < 0.12:
            grid[r][c] = "╲"
        elif abs(abs(f) - 1) < 0.12:
            grid[r][c] = "·"
sv = set(svm.support_)
for i, (x1, x2) in enumerate(X):
    r, c = round((1 - x2 / 7) * (H - 1)), round(x1 / 7 * (W - 1))
    if 0 <= r < H and 0 <= c < W:
        grid[r][c] = ("ⓢ" if y[i] else "ⓞ") if i in sv else ("●" if y[i] else "○")
for line in grid:
    print("  " + "".join(line))
```

       ╲      ··

    ··     ╲╲      ·       ●   ●●  ●      
      ··      ╲      ··●●     ●●   ●      
        ··      ╲╲     ⓢ·   ●● ●   ●

### 6-2. 원형 데이터 — 선형 vs 다항 vs RBF 커널
```python
import numpy as np
from sklearn.datasets import make_circles
from sklearn.svm import SVC

X, y = make_circles(n_samples=300, factor=0.4, noise=0.08, random_state=0)

for kernel, params in [("linear", {}), ("poly", {"degree": 2}), ("rbf", {})]:
    m = SVC(kernel=kernel, C=1.0, **params).fit(X, y)
    print(f"[{kernel:<6}] 정확도 {m.score(X, y):.0%}   서포트 벡터 {len(m.support_)}개")
    for r in range(9):
        row = ""
        for c in range(27):
            x1, x2 = -1.3 + c / 26 * 2.6, 1.3 - r / 8 * 2.6
            row += "●" if m.predict([[x1, x2]])[0] else "·"
        print("     " + row)
    print()
```

### 6-3. C와 γ의 영향, 그리고 스케일링의 중요성
```python
import numpy as np
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline
from sklearn.svm import SVC

X, y = make_moons(n_samples=400, noise=0.3, random_state=1)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)

print("(1) RBF SVM: C와 γ 조합별 훈련/테스트 정확도")
print("     γ\\C    0.1          1            100")
for g in [0.1, 1, 30]:
    cells = []
    for C in [0.1, 1, 100]:
        m = SVC(kernel="rbf", C=C, gamma=g).fit(X_tr, y_tr)
        cells.append(f"{m.score(X_tr, y_tr):.0%}/{m.score(X_te, y_te):.0%}")
    print(f"   {g:>4}   " + "    ".join(f"{c:<9}" for c in cells))

# (2) 스케일이 다른 특성: 두 번째 특성을 mm 단위처럼 1000배로 키움
X_big = X.copy()
X_big[:, 1] *= 1000
Xb_tr, Xb_te, yb_tr, yb_te = train_test_split(X_big, y, test_size=0.3, random_state=0)
raw = SVC(kernel="rbf").fit(Xb_tr, yb_tr)
scaled = make_pipeline(StandardScaler(), SVC(kernel="rbf")).fit(Xb_tr, yb_tr)
print("\n(2) 특성 하나를 1000배로 키웠을 때 테스트 정확도")
print(f"   스케일링 없음 : {raw.score(Xb_te, yb_te):.0%}  {'█' * round(raw.score(Xb_te, yb_te) * 30)}")
print(f"   StandardScaler: {scaled.score(Xb_te, yb_te):.0%}  {'█' * round(scaled.score(Xb_te, yb_te) * 30)}")
```
실행 결과
```
(1) RBF SVM: C와 γ 조합별 훈련/테스트 정확도
     γ\C    0.1          1            100
    0.1   82%/83%      84%/84%      90%/88%  
      1   88%/85%      90%/89%      91%/90%  
     30   76%/63%      92%/90%      96%/82%  

(2) 특성 하나를 1000배로 키웠을 때 테스트 정확도
   스케일링 없음 : 76%  ███████████████████████
   StandardScaler: 89%  ███████████████████████████
```
- 표의 각 칸은 `훈련/테스트` 정확도입니다. **γ와 C가 모두 크면** 훈련 정확도는 높지만 테스트 정확도가 떨어집니다 (과적합). **둘 다 작으면** 경계가 너무 단순해 둘 다 낮습니다 (과소적합).
- 단위가 다른 특성을 그대로 넣으면 SVM은 크기가 큰 특성 하나만 보게 됩니다. `StandardScaler`로 맞춰 주면 성능이 회복됩니다. **SVM을 쓸 때는 스케일링을 항상 같이** 하세요.

<summary>정답 보기</summary>

1. 양쪽 클래스에서 가장 가까운 점까지의 거리(마진)가 최대가 되는 경계
2. 마진 경계 위나 안쪽에 있어 경계 위치를 결정하는 점들. 서포트 벡터가 아닌 점은 지워도 경계가 바뀌지 않는다.
3. ‖w‖를 작게 해야 한다 (그래서 목표가 ½‖w‖² 최소화).
4. 마진 위반을 엄하게 벌주므로 길이 좁아지고 노이즈까지 맞추려 해서 과적합되기 쉽다.
5. 데이터를 실제로 고차원으로 변환하지 않고, 커널 함수로 고차원 내적 값만 바로 계산해 같은 효과를 얻기 때문
6. 점 하나하나 주위에 좁은 섬이 생기는 울퉁불퉁한 경계 → 과적합
7. 거리와 내적으로 계산하므로 값의 범위가 큰 특성이 결과를 지배하기 때문
