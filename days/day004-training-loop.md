# Day 004 — 학습의 기본 흐름: 모델, 손실 함수, 최적화, 데이터 분할

> 📅 2026-11-11 · 1부. 기초 개념 · ⏱ 예상 학습 시간 40~50분

## 1. 한 줄 요약
선형 회귀든 YOLO든 GPT든, 학습은 모두 같은 4단계 루프입니다. **① 모델이 예측하고 → ② 손실 함수로 얼마나 틀렸는지 재고 → ③ 최적화 알고리즘이 가중치를 조금 고치고 → ④ 반복**합니다. 그리고 이 과정이 진짜로 잘 되고 있는지는 **학습에 쓰지 않은 데이터(검증·테스트)** 로만 알 수 있습니다.

```
          ┌──────────────────────── 반복 (epoch × batch) ────────────────────────┐
          ▼                                                                      │
  배치 데이터 (x, y) ──▶ ① 모델 f(x; w) ──▶ 예측 ŷ ──▶ ② 손실 L(ŷ, y) ──▶ ③ 기울기 ∂L/∂w
                                                                                 │
                                         ④ w ← w − η · ∂L/∂w  (가중치 업데이트) ◀┘
```

## 2. 핵심 용어
| 용어 | 뜻 |
|---|---|
| 모델 (Model) | 가중치 w를 가진 함수 f(x; w). 구조(아키텍처)는 사람이 정하고 w는 학습으로 정해짐 |
| 파라미터 (Parameter) | 학습으로 바뀌는 값. 가중치(weight)와 편향(bias) |
| 하이퍼파라미터 (Hyperparameter) | 사람이 학습 전에 정하는 설정. 학습률, 배치 크기, 에포크 수, 층 개수 등 |
| 손실 함수 (Loss Function) | 예측이 정답과 얼마나 다른지 숫자 하나로 나타내는 함수. 작을수록 좋음 |
| 비용 함수 (Cost Function) | 데이터 전체(또는 배치)에 대한 손실의 평균. 실무에서는 손실과 거의 같은 뜻으로 씀 |
| 기울기 / 그래디언트 (Gradient) | 가중치를 조금 바꿨을 때 손실이 얼마나 변하는지. 손실이 커지는 방향을 가리킴 |
| 경사하강법 (Gradient Descent) | 기울기의 반대 방향으로 가중치를 조금씩 옮겨 손실을 줄이는 방법 |
| 학습률 (Learning Rate, η) | 한 번에 가중치를 얼마나 크게 옮길지 정하는 보폭 |
| 배치 / 미니배치 (Batch) | 한 번의 업데이트에 쓰는 데이터 묶음. 예: 32장 |
| 반복 (Iteration / Step) | 배치 하나로 가중치를 한 번 업데이트하는 것 |
| 에포크 (Epoch) | 학습 데이터 전체를 한 바퀴 다 보는 것 |
| 학습 곡선 (Learning Curve) | 에포크에 따른 학습 손실·검증 손실 그래프 |
| 조기 종료 (Early Stopping) | 검증 손실이 더 이상 좋아지지 않으면 학습을 멈추는 기법 |

## 3. 개념과 작동 원리

### 3-1. ① 모델 — 무엇을 배울 것인가
가장 단순한 모델은 직선입니다: `ŷ = w·x + b`. 학습이란 데이터에 가장 잘 맞는 `w`와 `b`를 찾는 일입니다. 신경망은 이런 식을 수백만~수천억 개 쌓은 것이지만, **"숫자(가중치)를 조정해 예측을 맞춘다"** 는 원리는 똑같습니다.

| 모델 | 파라미터 수 (대략) |
|---|---|
| 직선 `w·x + b` | 2 |
| YOLOv8n (가장 작은 버전) | 약 300만 |
| ResNet-50 | 약 2,500만 |
| GPT-3 | 1,750억 |

### 3-2. ② 손실 함수 — 얼마나 틀렸나
문제 종류에 따라 손실 함수를 고릅니다.

| 문제 | 손실 함수 | 식 (샘플 1개) | 직관 |
|---|---|---|---|
| 회귀 | **MSE** (평균제곱오차) | `(ŷ − y)²` | 크게 틀릴수록 제곱으로 크게 벌점. 이상치에 민감 |
| 회귀 | **MAE** (평균절대오차) | `\|ŷ − y\|` | 틀린 만큼만 벌점. 이상치에 강함 |
| 이진 분류 | **BCE** (이진 교차 엔트로피) | `−[y·log p + (1−y)·log(1−p)]` | 정답에 낮은 확률을 주면 벌점이 폭증 |
| 다중 분류 | **교차 엔트로피** (Cross-Entropy) | `−log p(정답 클래스)` | 정답 클래스 확률을 1에 가깝게 |
| 객체 탐지 (YOLO) | 여러 손실의 합 | 박스 위치 손실(IoU 계열) + 클래스 손실(BCE) + 물체 유무 손실 | Day 032에서 자세히 |

**교차 엔트로피 감 잡기**: 정답이 "고양이"일 때
- 모델이 고양이 확률 0.9를 주면 손실 = −log(0.9) ≈ **0.11**
- 0.5를 주면 ≈ **0.69**
- 0.01을 주면 ≈ **4.61** → 자신 있게 틀리면 크게 혼납니다.

### 3-3. ③ 최적화 — 어떻게 고칠까 (경사하강법)
손실을 가중치에 대한 "산 지형"이라고 생각하면, 경사하강법은 **안개 낀 산에서 발밑 경사만 보고 가장 가파르게 내려가는 방향으로 한 걸음씩 걷는 것**입니다.

```
손실 L
  │╲                         ╱
  │ ╲                       ╱
  │  ╲  ●  ← 시작          ╱
  │   ╲   ●               ╱
  │    ╲     ●          ╱
  │     ╲       ●  ●  ╱     ← 기울기가 0에 가까워지며 최저점에 수렴
  │      ╲___________╱
  └──────────────────────────── 가중치 w
                 최적의 w

업데이트 규칙:  w_new = w_old − η × (∂L/∂w)
```

**학습률 η 고르기**
| 학습률 | 결과 |
|---|---|
| 너무 작음 | 아주 천천히 내려감. 학습이 끝나지 않거나 시간이 오래 걸림 |
| 적당함 | 안정적으로 최저점 근처에 수렴 |
| 너무 큼 | 최저점을 넘나들며 진동하거나 손실이 오히려 발산(NaN) |

**배치 크기에 따른 세 가지 방식**
| 방식 | 한 번 업데이트에 쓰는 데이터 | 특징 |
|---|---|---|
| 배치 경사하강법 | 전체 데이터 | 정확하지만 느리고 메모리를 많이 씀 |
| 확률적 경사하강법 (SGD) | 1개 | 빠르지만 경로가 지그재그로 흔들림 |
| **미니배치 경사하강법** | 16~512개 | 둘의 절충. **실무 표준.** GPU 병렬 처리에 적합 |

> 계산 예: 학습 데이터 10,000장, 배치 크기 32 → 1 에포크 = 약 313번의 업데이트(iteration). 100 에포크면 약 31,300번 업데이트합니다.

Adam, AdamW 같은 더 똑똑한 옵티마이저는 Day 020에서, 기울기를 계산하는 방법(역전파)은 Day 019에서 다룹니다.

### 3-4. ④ 데이터 분할 — 진짜 실력을 재는 법
학습 데이터로 성적을 재면 **답안지를 외운 학생**을 칭찬하는 것과 같습니다. 그래서 데이터를 세 개로 나눕니다.

| 데이터 | 용도 | 비유 | 언제 보나 |
|---|---|---|---|
| 학습 (Train) | 가중치 업데이트 | 교과서·문제집 | 매 반복 |
| 검증 (Validation) | 하이퍼파라미터 선택, 조기 종료, 모델 비교 | 모의고사 | 매 에포크 끝 |
| 테스트 (Test) | 최종 성능 보고 | 수능 | **맨 마지막에 딱 한 번** |

**왜 검증과 테스트를 따로 두나?** 검증 점수를 보면서 학습률, 모델 크기를 계속 바꾸면 결국 검증 데이터에도 맞춰진 모델이 됩니다. 그래서 한 번도 보지 않은 테스트 데이터가 따로 있어야 정직한 점수가 나옵니다.

**분할 비율과 방법**
- 보통 70/15/15 또는 80/10/10. 데이터가 수백만 개면 98/1/1도 충분합니다.
- **층화 분할 (Stratified)**: 클래스 비율을 각 세트에 똑같이 유지합니다. 불량품이 2%뿐인 데이터에서 특히 중요합니다.
- **K-폴드 교차 검증 (K-Fold CV)**: 데이터가 적을 때 사용합니다. 데이터를 K조각으로 나눠 돌아가며 1조각을 검증용으로 쓰고, K번의 평균으로 평가합니다.
- **시계열·영상**: 무작위로 섞지 말고 시간 순서로 나눕니다. 같은 영상에서 뽑은 연속 프레임이 학습과 테스트에 나뉘어 들어가면 거의 같은 사진이 양쪽에 생겨 점수가 부풀려집니다.

## 4. 구조 — 학습 곡선 읽는 법
학습 중 매 에포크마다 학습 손실과 검증 손실을 기록하면, 모델 상태를 진단할 수 있습니다.

```
손실                                   손실                                  손실
 │╲                                     │╲                                   │╲
 │ ╲                                    │ ╲___  검증                         │ ╲___________  검증
 │  ╲____  검증                         │  ╲  ╲___╱‾‾‾  ← 다시 올라감          │  ╲__________  학습
 │   ╲___  학습                         │   ╲____                           │
 │       ‾‾‾‾‾‾‾‾                       │        ╲_____  학습                │  (둘 다 높게 정체)
 └──────────── 에포크                    └──────────── 에포크                  └──────────── 에포크
  ✅ 잘 학습됨                            ⚠️ 과적합 (Overfitting)               ⚠️ 과소적합 (Underfitting)
  두 곡선이 함께 내려가 비슷한 값에서 수렴   학습 손실↓ 검증 손실↑ → 외우는 중         모델이 너무 단순하거나 학습이 부족
                                         → 조기 종료, 데이터 증강, 정규화         → 더 큰 모델, 더 오래 학습
```
과적합과 과소적합은 Day 005에서 자세히 다룹니다.

| AI 벤치마크 | 평가 문제가 학습 데이터에 섞이는 "오염(contamination)"을 막으려고 문제를 비공개로 운영 (오늘의 소식 참고) |

## 6. 코드로 보기

### 6-1. NumPy로 직접 구현하는 학습 루프 (선형 회귀)
```python
import numpy as np

rng = np.random.default_rng(0)
x = rng.uniform(0, 10, 200)
y = 3 * x + 5 + rng.normal(0, 2, 200)          # 진짜 정답: w=3, b=5 (+ 노이즈)

# ④ 데이터 분할: 학습 140 / 검증 30 / 테스트 30
idx = rng.permutation(200)
tr, va, te = idx[:140], idx[140:170], idx[170:]

w, b = 0.0, 0.0                                 # ① 모델 ŷ = w·x + b, 가중치 초기화
lr, epochs, batch = 0.01, 50, 20                # 하이퍼파라미터
mse = lambda yh, yt: np.mean((yh - yt) ** 2)    # ② 손실 함수

best_val, patience, wait = np.inf, 5, 0
for epoch in range(epochs):
    rng.shuffle(tr)                             # 매 에포크마다 학습 데이터 섞기
    for i in range(0, len(tr), batch):          # 미니배치
        bi = tr[i:i + batch]
        y_hat = w * x[bi] + b                   # 순전파(예측)
        err = y_hat - y[bi]
        dw, db = 2 * np.mean(err * x[bi]), 2 * np.mean(err)   # ③ 기울기
        w, b = w - lr * dw, b - lr * db                       #    경사하강 업데이트
    tr_loss = mse(w * x[tr] + b, y[tr])
    va_loss = mse(w * x[va] + b, y[va])
    if epoch % 10 == 0:
        print(f"epoch {epoch:2d}  train {tr_loss:6.2f}  val {va_loss:6.2f}  w={w:.2f} b={b:.2f}")
    if va_loss < best_val - 1e-3:               # 조기 종료 판단은 검증 손실로
        best_val, wait = va_loss, 0
    else:
        wait += 1
        if wait >= patience:
            print(f"조기 종료 @ epoch {epoch}")
            break

print(f"최종 w={w:.2f}, b={b:.2f}  |  테스트 MSE = {mse(w * x[te] + b, y[te]):.2f}")  # 테스트는 마지막에 한 번
```

### 6-2. 같은 루프를 PyTorch로 (실무 형태)
```python
# pip install torch
import torch, torch.nn as nn

model = nn.Linear(1, 1)                                  # ① 모델
loss_fn = nn.MSELoss()                                   # ② 손실 함수
optimizer = torch.optim.SGD(model.parameters(), lr=0.01) # ③ 최적화 알고리즘

for epoch in range(50):
    model.train()
    for xb, yb in train_loader:                          # 미니배치 (DataLoader)
        y_hat = model(xb)                                # 예측
        loss = loss_fn(y_hat, yb)                        # 손실 계산
        optimizer.zero_grad()                            # 이전 기울기 초기화
        loss.backward()                                  # 기울기 계산 (역전파)
        optimizer.step()                                 # 가중치 업데이트
    model.eval()
    with torch.no_grad():                                # 검증 때는 기울기 계산 안 함
        val_loss = sum(loss_fn(model(xb), yb).item() for xb, yb in val_loader) / len(val_loader)
```
PyTorch 학습 코드는 거의 항상 **`예측 → loss 계산 → zero_grad → backward → step`** 다섯 줄의 반복입니다. 이 순서를 외워 두면 어떤 모델 코드든 읽을 수 있습니다. (Day 023에서 자세히)
