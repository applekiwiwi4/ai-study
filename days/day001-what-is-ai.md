# Day 001 — 인공지능이란? AI·머신러닝·딥러닝의 관계와 역사

> 📅 2026-11-08 · 1부. 기초 개념 · ⏱ 예상 학습 시간 30~40분

## 1. 한 줄 요약
**인공지능(AI)** 은 사람의 지능적 행동을 기계가 하게 만드는 기술 전체를 말합니다. **머신러닝(ML)** 은 그 안에서 *규칙을 사람이 짜지 않고 데이터로부터 학습*하는 방법이고, **딥러닝(DL)** 은 머신러닝 중에서 *여러 층의 인공 신경망*을 쓰는 방법입니다.

```
┌──────────────────────────── 인공지능 (AI) ────────────────────────────┐
│  규칙 기반 시스템, 탐색, 전문가 시스템 ...                               │
│   ┌──────────────────── 머신러닝 (ML) ────────────────────┐            │
│   │  선형 회귀, 결정 트리, SVM, k-means ...                │            │
│   │   ┌───────────── 딥러닝 (DL) ─────────────┐           │            │
│   │   │  CNN, RNN, Transformer, YOLO, GPT ... │           │            │
│   │   └───────────────────────────────────────┘           │            │
│   └───────────────────────────────────────────────────────┘            │
└───────────────────────────────────────────────────────────────────────────┘
```

## 2. 핵심 용어
| 용어 | 뜻 |
|---|---|
| 인공지능 (Artificial Intelligence) | 인식·추론·학습·판단 같은 지능적 작업을 컴퓨터가 수행하게 하는 기술 전체 |
| 머신러닝 (Machine Learning) | 명시적인 규칙 대신 데이터에서 패턴을 학습해 예측·결정하는 방법 |
| 딥러닝 (Deep Learning) | 여러 층(layer)의 인공 신경망으로 데이터의 특징을 스스로 뽑아내 학습하는 머신러닝 |
| 모델 (Model) | 입력을 받아 출력을 내는 학습된 함수. 예: 사진 → "고양이" |
| 파라미터 / 가중치 (Weight) | 모델이 학습을 통해 조정하는 숫자들. 모델의 "지식"이 저장되는 곳 |
| 학습 (Training) | 데이터를 보여주며 가중치를 조정하는 과정 |
| 추론 (Inference) | 학습이 끝난 모델로 새 입력에 대한 결과를 내는 과정 |
| 특징 (Feature) | 모델이 판단에 쓰는 입력의 속성. 예: 집 면적, 픽셀 밝기 |
| 레이블 (Label) | 정답 데이터. 예: 사진마다 붙은 "개/고양이" |
| 약인공지능 (Narrow AI) | 특정 작업만 잘하는 AI. 현재 대부분의 AI가 여기에 속함 |
| 범용 인공지능 (AGI) | 사람처럼 다양한 분야의 일을 두루 해내는 AI. 아직 연구 목표 단계 |

## 3. 개념과 작동 원리 — 전통적 프로그래밍과 머신러닝의 차이

```
[전통적 프로그래밍]   데이터 + 규칙(사람이 작성)  ──▶  결과
[머신러닝]           데이터 + 결과(정답)        ──▶  규칙(모델이 학습)
```

**예시: 스팸 메일 분류**
- 전통 방식: "제목에 '무료', '당첨'이 있으면 스팸" 같은 규칙을 사람이 계속 추가합니다. 스팸 수법이 바뀌면 규칙을 다시 고쳐야 합니다.
- 머신러닝: 스팸/정상으로 표시된 메일 수만 통을 주면, 모델이 어떤 단어 조합이 스팸과 관련 있는지 스스로 찾아냅니다.

**머신러닝 vs 딥러닝의 핵심 차이는 "특징을 누가 뽑느냐"입니다.**
- 머신러닝: 사람이 특징을 설계합니다 (특징 공학, Feature Engineering). 예: 이미지에서 모서리 개수, 색상 히스토그램을 직접 계산.
- 딥러닝: 원본 데이터(픽셀 그대로)를 넣으면 신경망의 층들이 단계별로 특징을 스스로 학습합니다. 앞쪽 층은 선·모서리, 중간 층은 눈·바퀴 같은 부분, 뒤쪽 층은 "얼굴", "자동차" 같은 전체 개념을 잡아냅니다.

| 비교 | 머신러닝 | 딥러닝 |
|---|---|---|
| 특징 추출 | 사람이 설계 | 모델이 자동 학습 |
| 필요 데이터 양 | 적어도 동작 | 많을수록 유리 (수만~수십억 건) |
| 연산 자원 | CPU로 충분한 경우가 많음 | GPU가 사실상 필수 |
| 해석 가능성 | 비교적 쉬움 (결정 트리 등) | 어려움 (블랙박스) |
| 강한 분야 | 표 형태 데이터 (매출, 고객 정보) | 이미지, 음성, 텍스트 등 비정형 데이터 |

## 4. 구조 — 학습하는 모델의 기본 구조
오늘은 모든 모델에 공통인 큰 틀만 봅니다. 신경망 내부 구조는 Day 017부터 자세히 다룹니다.

```
입력 x ──▶ [ 모델 f(x; w) ] ──▶ 예측 ŷ
                 ▲                    │
                 │                    ▼
          가중치 w 수정 ◀── 손실 L(ŷ, y) ◀── 정답 y
            (최적화)        (얼마나 틀렸나)
```
1. **입력**을 모델에 넣어 **예측**을 얻습니다.
2. 예측과 **정답**을 비교해 **손실(오차)** 을 계산합니다.
3. 손실이 줄어드는 방향으로 **가중치**를 조금씩 수정합니다.
4. 이 과정을 수천~수백만 번 반복하면 모델이 점점 정확해집니다.

| 2016 | 알파고, 이세돌 9단에게 승리 | 딥러닝 + 강화학습의 위력 |
| 2017 | Transformer 논문 "Attention Is All You Need" | 현재 LLM의 기반 구조 |
| 2022~ | ChatGPT 등 대규모 언어 모델 대중화 | 생성형 AI 시대 |
| 현재 | 멀티모달 모델, AI 에이전트, 로봇 파운데이션 모델 | 보고·듣고·행동하는 AI로 확장 중 |

**딥러닝이 2012년에 갑자기 뜬 이유 3가지**
1. **데이터**: 인터넷과 스마트폰으로 대량의 이미지·텍스트가 쌓임 (ImageNet 약 1,400만 장)
2. **연산**: GPU의 병렬 연산이 신경망 학습에 딱 맞았음
3. **알고리즘**: ReLU, 드롭아웃 같은 학습 기법으로 깊은 망도 학습 가능해짐

## 7. 코드로 보기 — 규칙 vs 학습
같은 문제(공부 시간 → 합격 여부)를 두 방식으로 풀어 봅니다.

```python
# pip install scikit-learn
from sklearn.linear_model import LogisticRegression

# ① 전통적 프로그래밍: 사람이 규칙을 정함
def rule_based(hours):
    return "합격" if hours >= 5 else "불합격"   # 기준 5시간은 사람이 정한 값

# ② 머신러닝: 데이터에서 기준을 학습
hours  = [[1], [2], [3], [4], [6], [7], [8], [9]]   # 입력(특징)
passed = [ 0,   0,   0,   1,   1,   1,   1,   1 ]   # 정답(레이블)

model = LogisticRegression()
model.fit(hours, passed)                 # 학습

for h in [2.5, 3.5, 4.5]:
    prob = model.predict_proba([[h]])[0][1]
    print(f"{h}시간 → 규칙: {rule_based(h)}, 모델 합격 확률: {prob:.2f}")
```
모델은 "몇 시간부터 합격인가"라는 기준을 사람이 알려주지 않아도 데이터에서 찾아내고, 확률로 결과를 냅니다. 이것이 머신러닝의 핵심입니다.
