# Day 005 — 과적합과 과소적합, 편향-분산 트레이드오프, 정규화(L1/L2)

## 1. 한 줄 요약
좋은 모델은 학습 데이터를 **외우는** 모델이 아니라 처음 보는 데이터에서도 잘 맞히는 **일반화**가 된 모델입니다. 모델이 너무 단순하면 패턴을 못 잡고(**과소적합**), 너무 복잡하면 노이즈까지 외웁니다(**과적합**). 이 사이의 균형이 **편향-분산 트레이드오프**이고, 복잡한 모델을 길들이는 대표 도구가 **정규화**입니다.

```
     과소적합 (Underfitting)        적절함 (Good fit)            과적합 (Overfitting)
   y│   ·   ·  ·                 y│   ·   ·  ·                y│   ·   ·  ·
    │ ·  ───────── ·              │ ·  ╭───╮   ·               │ · ╱╲╭╮ ╱╲ ·
    │  ·   ·    ·                 │  ·╱ ·   ╲·                 │  ╱·  ╰╯·  ╲╱·
    │ ·      ·                    │ ╱·      ·╲                 │ ╱      ·    ╲
    └──────────── x               └──────────── x              └──────────── x
   직선 하나로 곡선을 설명          데이터의 큰 흐름을 따라감     점 하나하나를 다 지나가려 함
   학습 오차 ↑  검증 오차 ↑         학습 오차 ↓  검증 오차 ↓      학습 오차 ≈0  검증 오차 ↑↑
```

## 2. 핵심 용어
| 용어 | 뜻 |
|---|---|
| 일반화 (Generalization) | 학습에 쓰지 않은 새 데이터에서도 잘 동작하는 능력. 머신러닝의 진짜 목표 |
| 과적합 (Overfitting) | 학습 데이터의 노이즈와 우연한 패턴까지 외워서, 새 데이터에서 성능이 떨어지는 상태 |
| 과소적합 (Underfitting) | 모델이 너무 단순하거나 학습이 부족해서 학습 데이터조차 잘 못 맞히는 상태 |
| 모델 복잡도 (Capacity) | 모델이 표현할 수 있는 함수의 다양성. 파라미터 수, 다항식 차수, 트리 깊이 등 |
| 편향 (Bias) | 모델의 가정이 너무 단순해서 생기는 **체계적인** 오차. "늘 같은 방향으로 빗나감" |
| 분산 (Variance) | 학습 데이터가 조금만 바뀌어도 모델이 크게 달라지는 **불안정성** |
| 노이즈 (Irreducible Error) | 데이터 자체에 들어 있는, 어떤 모델로도 줄일 수 없는 오차 |
| 일반화 격차 (Generalization Gap) | 검증 오차 − 학습 오차. 클수록 과적합 의심 |
| 정규화 (Regularization) | 모델이 너무 복잡해지지 않도록 제약(벌점)을 주는 모든 기법 |
| L1 정규화 (Lasso) | 가중치 절댓값의 합에 벌점. 쓸모없는 가중치를 **정확히 0**으로 만들어 특징을 골라냄 |
| L2 정규화 (Ridge, Weight Decay) | 가중치 제곱합에 벌점. 가중치를 **전체적으로 작게** 만들어 부드러운 모델을 만듦 |
| λ (람다, alpha) | 정규화 강도. 클수록 모델이 단순해짐 |

## 3. 개념과 작동 원리

### 3-1. 과적합과 과소적합 진단표
| 상태 | 학습 오차 | 검증 오차 | 원인 | 처방 |
|---|---|---|---|---|
| **과소적합** | 높음 | 높음 (학습과 비슷) | 모델이 너무 단순, 특징 부족, 학습 부족 | 더 큰/복잡한 모델, 특징 추가, 더 오래 학습, 정규화 줄이기 |
| **적절함** | 낮음 | 낮음 (학습보다 약간 높음) | — | 유지 |
| **과적합** | 매우 낮음 | 높음 (격차 큼) | 모델이 너무 복잡, 데이터 부족, 너무 오래 학습 | 데이터 추가·증강, 정규화, 드롭아웃, 조기 종료, 더 작은 모델 |

**시험 공부 비유**
- 과소적합: 교과서를 대충 읽어서 연습문제도, 시험도 못 품
- 과적합: 기출문제 답을 번호째 외워서 기출은 100점인데, 숫자만 바뀐 시험 문제는 못 품
- 일반화: 원리를 이해해서 처음 보는 문제도 품

### 3-2. 편향-분산 트레이드오프
예측 오차는 세 부분으로 나눌 수 있습니다.

```
기대 오차  =  편향²  +  분산  +  줄일 수 없는 노이즈
```

과녁에 비유하면 이해가 쉽습니다. 같은 모델 구조를 서로 다른 학습 데이터로 여러 번 학습시켰을 때 예측이 어디에 꽂히는지를 보는 겁니다.

```
              낮은 분산                         높은 분산
         ┌─────────────────┐            ┌─────────────────┐
 낮은     │      ◎          │            │   ·    ◎    ·   │
 편향     │     ●●●         │            │      ·    ·     │
         │      ●          │            │  ·      ·       │
         │   ✅ 이상적      │            │   ⚠️ 과적합      │
         └─────────────────┘            └─────────────────┘
         ┌─────────────────┐            ┌─────────────────┐
 높은     │      ◎          │            │  ·   ◎          │
 편향     │                 │            │        ·    ·   │
         │  ●●●            │            │ ·   ·           │
         │   ⚠️ 과소적합    │            │   ❌ 최악        │
         └─────────────────┘            └─────────────────┘
   ◎ = 정답(과녁 중심)   ● = 모델 예측
```

**모델 복잡도에 따른 변화**
```
오차
 │ ╲                                       ╱  ← 분산 (복잡할수록 커짐)
 │  ╲                                    ╱
 │   ╲         ___________             ╱
 │    ╲      ╱   총 오차    ╲         ╱
 │     ╲   ╱                ╲     ╱
 │      ╲╱                    ╲ ╱
 │      ╱╲  ← 최적 지점         ╳
 │    ╱    ╲________________╱    ╲
 │  ╱  편향² (복잡할수록 작아짐)     ╲___
 └──────────────────────────────────────── 모델 복잡도
   과소적합 영역      ↑ 최적      과적합 영역
```
- 단순한 모델(직선): 편향 ↑, 분산 ↓
- 복잡한 모델(고차 다항식, 거대한 신경망): 편향 ↓, 분산 ↑
- 목표: 총 오차가 가장 낮은 복잡도를 찾기 → **검증 세트로 고릅니다** (Day 004)

> 💡 **딥러닝에서의 반전 — 이중 하강 (Double Descent)**: 신경망은 파라미터가 데이터보다 훨씬 많아도 잘 일반화하는 경우가 많습니다. 복잡도를 더 키우면 검증 오차가 한 번 올라갔다가 **다시 내려가는** 현상이 관찰됩니다. 그래서 딥러닝에서는 "모델을 줄이기"보다 "큰 모델 + 정규화 + 많은 데이터" 조합을 주로 씁니다.

### 3-3. 정규화 — 복잡도에 벌점 주기
원래 손실에 **가중치 크기에 대한 벌점**을 더해서, 꼭 필요한 경우에만 가중치가 커지도록 만듭니다.

```
L2 (Ridge):   전체 손실 = 원래 손실 + λ · Σ w²
L1 (Lasso):   전체 손실 = 원래 손실 + λ · Σ |w|
Elastic Net:  전체 손실 = 원래 손실 + λ₁ · Σ |w| + λ₂ · Σ w²
```

| 비교 | L1 (Lasso) | L2 (Ridge / Weight Decay) |
|---|---|---|
| 벌점 | 가중치 절댓값 | 가중치 제곱 |
| 효과 | 일부 가중치를 **정확히 0**으로 | 모든 가중치를 **골고루 작게** |
| 결과 | 희소(sparse) 모델, 자동 특징 선택 | 부드럽고 안정적인 모델 |
| 언제 | 특징이 많은데 일부만 중요할 때 | 기본값. 특징들이 서로 연관돼 있을 때 |
| 딥러닝에서 | 드물게 사용 | `weight_decay` 옵션으로 거의 항상 사용 (AdamW) |

**왜 L1은 0을 만들고 L2는 작게만 만들까?** (기하학적 직관)
```
       w₂                              w₂
        │    손실 등고선                  │    손실 등고선
        │   ╭──╮                         │   ╭──╮
        ◆  (  ● )                        ○  (  ● )
       ╱│╲  ╰──╯                        (│)  ╰──╯
  ────◆─┼─◆──── w₁                  ────(┼)──── w₁
       ╲│╱                              (│)
        ◆                                ○
   L1 제약 = 마름모                  L2 제약 = 원
   → 꼭짓점(축 위)에서 만나기 쉬움     → 아무 데서나 매끄럽게 만남
   → w₁=0 같은 해가 잘 나옴           → 0은 잘 안 나오고 작아지기만 함
```

## 6. 코드로 보기

### 6-1. 다항식 차수로 보는 과소적합 vs 과적합
```python
# pip install scikit-learn numpy
import numpy as np
from sklearn.preprocessing import PolynomialFeatures, StandardScaler
from sklearn.linear_model import LinearRegression, Ridge
from sklearn.pipeline import make_pipeline
from sklearn.metrics import mean_squared_error

rng = np.random.default_rng(42)
X = np.sort(rng.uniform(0, 1, 30)).reshape(-1, 1)
y = np.sin(2 * np.pi * X).ravel() + rng.normal(0, 0.2, 30)      # 진짜 패턴: sin 곡선 + 노이즈
X_val = np.sort(rng.uniform(0, 1, 100)).reshape(-1, 1)
y_val = np.sin(2 * np.pi * X_val).ravel() + rng.normal(0, 0.2, 100)

print(f"{'차수':>4} | {'학습 MSE':>8} | {'검증 MSE':>8} | 진단")
for degree in [1, 4, 15]:
    model = make_pipeline(PolynomialFeatures(degree), StandardScaler(), LinearRegression())
    model.fit(X, y)
    tr = mean_squared_error(y, model.predict(X))
    va = mean_squared_error(y_val, model.predict(X_val))
    diag = "과소적합" if tr > 0.1 else ("과적합" if va - tr > 0.05 else "적절")   # 일반화 격차로 판단
    print(f"{degree:>4} | {tr:8.3f} | {va:8.3f} | {diag}")

# ② 15차 다항식(과적합)에 L2 정규화를 걸면?
print("\n15차 다항식 + Ridge(L2)")
for alpha in [1e-6, 1e-3, 1e-1, 10]:
    model = make_pipeline(PolynomialFeatures(15), StandardScaler(), Ridge(alpha=alpha))
    model.fit(X, y)
    tr = mean_squared_error(y, model.predict(X))
    va = mean_squared_error(y_val, model.predict(X_val))
    print(f"alpha={alpha:<6} 학습 {tr:.3f}  검증 {va:.3f}")
```
실행 결과 (seed 42 기준)
```
  차수 |   학습 MSE |   검증 MSE | 진단
   1 |    0.187 |    0.239 | 과소적합
   4 |    0.025 |    0.053 | 적절
  15 |    0.016 |    0.089 | 과적합

15차 다항식 + Ridge(L2)
alpha=1e-06  학습 0.020  검증 0.055
alpha=0.001  학습 0.023  검증 0.052
alpha=0.1    학습 0.032  검증 0.087
alpha=10     학습 0.089  검증 0.174
```
- 1차(직선): 학습·검증 오차가 모두 큼 → 과소적합
- 4차: 둘 다 낮고 격차도 작음 → 적절
- 15차: 학습 오차는 **가장 낮은데** 검증 오차는 4차보다 큼 → 과적합
- 15차 + Ridge: 약한 정규화(alpha=0.001)만 걸어도 검증 오차가 0.089 → 0.052로 4차 수준까지 좋아짐. 너무 세게 걸면(alpha=10) 학습 오차까지 커져 다시 과소적합

### 6-2. L1(Lasso)이 특징을 골라내는 모습
```python
from sklearn.linear_model import Lasso, Ridge
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(size=(200, 10))                      # 특징 10개
y = 3 * X[:, 0] - 2 * X[:, 1] + rng.normal(0, 0.5, 200)   # 실제로 쓰이는 건 0번, 1번뿐

print("Lasso(L1):", np.round(Lasso(alpha=0.1).fit(X, y).coef_, 2))
print("Ridge(L2):", np.round(Ridge(alpha=10).fit(X, y).coef_, 2))
# Lasso는 쓸모없는 8개 특징의 가중치를 정확히 0으로 만들고,
# Ridge는 전부 작게 남겨 둔다.
```

## 7. 복습 퀴즈
1. 학습 정확도 99%, 검증 정확도 70%인 모델은 어떤 상태인가요?
2. 학습 정확도 60%, 검증 정확도 58%인 모델은 어떤 상태이고, 무엇을 먼저 시도해야 하나요?
3. 편향과 분산을 한 문장씩으로 설명해 보세요.
4. L1과 L2 정규화 중 "쓸모없는 특징을 자동으로 제거"하는 효과가 있는 것은?
5. 정규화 강도 λ를 너무 크게 하면 어떤 일이 생기나요?
6. 사진 300장으로 안전모 감지 YOLO를 학습했더니 현장 CCTV에서 성능이 크게 떨어졌습니다. 가능한 원인과 대책 두 가지는?

<details>
<summary>정답 보기</summary>

1. 과적합 (일반화 격차가 큼, 높은 분산)
2. 과소적합 (높은 편향). 더 큰 모델, 특징 추가, 더 오래 학습, 정규화 줄이기를 먼저 시도한다.
3. 편향: 모델이 너무 단순해서 늘 같은 방향으로 빗나가는 오차. 분산: 학습 데이터가 조금만 바뀌어도 예측이 크게 흔들리는 정도.
4. L1 (Lasso)
5. 모델이 지나치게 단순해져 과소적합이 된다.
6. 원인: 데이터가 적고 촬영 환경(조명·각도·배경)이 현장과 달라 학습 환경에 과적합. 대책: 현장과 비슷한 환경의 데이터 추가 수집, 밝기·각도·배경 증강, 사전학습 가중치 사용, 조기 종료.
</details>
