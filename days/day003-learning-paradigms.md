# Day 003 — 지도학습·비지도학습·강화학습

> 📅 2026-11-10 · 1부. 기초 개념 · ⏱ 예상 학습 시간 40~50분

## 1. 한 줄 요약
머신러닝은 **무엇을 보고 배우느냐**에 따라 세 가지로 나뉩니다. **지도학습**은 정답이 붙은 데이터로, **비지도학습**은 정답 없이 데이터의 구조를 스스로 찾고, **강화학습**은 행동해 보고 받은 **보상**으로 배웁니다. 요즘은 이 사이에 있는 **자기지도학습**이 LLM과 비전 파운데이션 모델의 핵심입니다.

```
                       머신러닝 학습 방식
     ┌───────────────────┬───────────────────┬───────────────────┐
  지도학습             비지도학습            강화학습
  (정답 있음)          (정답 없음)           (보상 신호)
  "이건 고양이야"      "비슷한 것끼리        "잘했어 +1
                        묶어 봐"             / 넘어졌어 −1"
  ├ 분류              ├ 군집화              ├ 가치 기반 (Q-Learning, DQN)
  └ 회귀              ├ 차원 축소           └ 정책 기반 (PPO)
                      └ 이상 탐지
     └──────── 중간 지대: 준지도학습 · 자기지도학습 ────────┘
```

## 2. 핵심 용어
| 용어 | 뜻 |
|---|---|
| 지도학습 (Supervised) | 입력 X와 정답 y 쌍으로 X → y 관계를 학습 |
| 분류 (Classification) | 정답이 범주인 문제. 예: 안전모 착용 / 미착용 |
| 회귀 (Regression) | 정답이 연속된 숫자인 문제. 예: 집값, 물체까지의 거리 |
| 비지도학습 (Unsupervised) | 정답 없이 데이터의 패턴, 그룹, 구조를 찾음 |
| 군집화 (Clustering) | 비슷한 샘플끼리 묶기. 예: 고객 세분화 |
| 차원 축소 (Dimensionality Reduction) | 특징 수를 줄이면서 핵심 정보를 남기기. 예: PCA |
| 이상 탐지 (Anomaly Detection) | "정상"에서 벗어난 샘플 찾기 |
| 강화학습 (Reinforcement) | 에이전트가 환경에서 행동하고 보상을 받으며 최선의 행동 전략을 학습 |
| 에이전트 / 환경 | 행동하는 주체(로봇, 게임 AI) / 에이전트가 상호작용하는 세계 |
| 상태 · 행동 · 보상 | 지금 상황(s) · 할 수 있는 선택(a) · 그 결과로 받는 점수(r) |
| 정책 (Policy, π) | "이 상태에서는 이 행동을 하라"는 에이전트의 전략 |
| 준지도학습 (Semi-supervised) | 소량의 정답 데이터 + 대량의 정답 없는 데이터로 학습 |
| 자기지도학습 (Self-supervised) | 데이터 자체에서 정답을 만들어 학습. 예: 다음 단어 맞히기, 가린 부분 복원 |

## 3. 개념과 작동 원리

### 3-1. 지도학습 — 정답을 보고 배운다
```
학습:  (사진1, "안전모 O"), (사진2, "안전모 X"), ... ──▶ 모델이 차이를 학습
추론:  새 사진 ──▶ 모델 ──▶ "안전모 X (확률 0.93)"
```
- **분류**: 출력이 범주. 이진 분류(O/X), 다중 분류(개/고양이/새)
- **회귀**: 출력이 숫자. 예: 카메라 영상으로 물체 중심의 x, y 좌표를 예측
- **객체 탐지(YOLO)는 둘 다 합니다.** 박스 안 물체가 무엇인지는 *분류*, 박스의 위치와 크기는 *회귀*입니다.
- 단점: **라벨링 비용**. 바운딩 박스 수천~수만 장을 사람이 직접 그려야 합니다.

### 3-2. 비지도학습 — 정답 없이 구조를 찾는다
| 과제 | 하는 일 | 대표 알고리즘 | 예시 |
|---|---|---|---|
| 군집화 | 비슷한 것끼리 묶기 | k-means, DBSCAN | 고객을 구매 패턴별 그룹으로 나누기 |
| 차원 축소 | 정보는 남기고 특징 수 줄이기 | PCA, t-SNE, UMAP | 512차원 얼굴 임베딩을 2D 그림으로 보기 |
| 이상 탐지 | 정상 패턴에서 벗어난 것 찾기 | Isolation Forest, 오토인코더 | 평소와 다른 DB 접근 로그 찾기 |
| 연관 규칙 | 함께 일어나는 것 찾기 | Apriori | "라면을 사면 계란도 산다" |

비지도학습의 결과는 사람이 해석해야 합니다. k-means는 고객을 3그룹으로 나눠 줄 뿐, 각 그룹이 "알뜰형", "충성형"이라는 이름은 사람이 붙입니다.

### 3-3. 강화학습 — 해 보고, 보상으로 배운다
```
          ┌──────────── 행동 aₜ ────────────┐
          │                                 ▼
   ┌─────────────┐                   ┌─────────────┐
   │  에이전트    │                   │    환경      │
   │ (정책 π)    │                   │ (로봇·게임)   │
   └─────────────┘                   └─────────────┘
          ▲                                 │
          └──── 다음 상태 sₜ₊₁, 보상 rₜ ─────┘
```
1. 에이전트가 현재 **상태**를 보고 **행동**을 고릅니다.
2. 환경이 바뀌고 **보상**과 **다음 상태**를 돌려줍니다.
3. 에이전트는 **장기적인 보상의 합(누적 보상)** 이 최대가 되도록 정책을 고칩니다.

**핵심 개념 두 가지**
- **탐험 vs 활용 (Exploration vs Exploitation)**: 아는 좋은 행동만 반복하면(활용) 더 좋은 방법을 못 찾고, 새로운 행동만 하면(탐험) 점수를 못 냅니다. 예: ε-greedy는 확률 ε만큼 무작위로 행동합니다.
- **지연된 보상**: 바둑에서 승패는 마지막에 나옵니다. 어떤 수가 승리에 기여했는지 거꾸로 따져야 합니다. 그래서 "지금 보상 + 미래 보상의 할인된 합"을 계산합니다 (할인율 γ).

**지도학습과의 차이**: 정답 행동을 알려주지 않습니다. "그 행동이 좋았다/나빴다"는 점수만 줄 뿐입니다.

### 3-4. 중간 지대 — 요즘 AI의 진짜 주인공
| 방식 | 아이디어 | 예시 |
|---|---|---|
| 준지도학습 | 라벨 100장 + 라벨 없는 1만 장. 모델이 자신 있게 예측한 것을 가짜 라벨(pseudo-label)로 다시 학습 | 의료 영상, 공장 불량 검사 |
| 자기지도학습 | 데이터 일부를 가리고 맞히게 해서 정답을 공짜로 만듦 | GPT(다음 단어 예측), BERT(가린 단어 맞히기), MAE(가린 이미지 패치 복원) |
| 모방학습 | 사람의 시연을 정답으로 삼는 지도학습 | 로봇 원격 조종 데이터로 동작 학습 |

> **LLM 학습 = 자기지도학습(사전학습) → 지도학습(지시 파인튜닝) → 강화학습(RLHF)**. 세 방식이 한 모델 안에 모두 들어갑니다. (Day 045~046에서 자세히)

## 4. 구조 — 세 방식을 한 장으로 비교
| 구분 | 지도학습 | 비지도학습 | 강화학습 |
|---|---|---|---|
| 데이터 | (입력, 정답) 쌍 | 입력만 | 환경과 상호작용하며 생성 |
| 피드백 | 매 샘플마다 정답 | 없음 | 행동 후 보상 (지연될 수 있음) |
| 목표 | 정답을 맞히는 함수 학습 | 숨은 구조·패턴 발견 | 누적 보상 최대화 |
| 출력 | 클래스, 숫자 | 그룹, 저차원 표현, 이상 점수 | 행동 정책 |
| 평가 | 정확도, mAP, MSE | 실루엣 점수 등 (애매함) | 누적 보상, 성공률 |
| 대표 모델 | 로지스틱 회귀, CNN, YOLO | k-means, PCA, 오토인코더 | Q-Learning, DQN, PPO |
| 어려운 점 | 라벨링 비용 | 결과 해석 | 학습 불안정, 많은 시행착오 |

**어떤 방식을 쓸까? 간단한 결정 흐름**
```
정답(라벨)이 있나?
 ├─ 있다 ──────────────▶ 지도학습 (범주면 분류, 숫자면 회귀)
 ├─ 조금 있다 ─────────▶ 준지도 / 사전학습 모델 + 파인튜닝
 ├─ 없다 ──────────────▶ 비지도학습 (묶기? 줄이기? 이상한 것 찾기?)
 └─ 정답 대신 "결과가 좋았는지"만 알 수 있다 (연속된 결정) ──▶ 강화학습
```

## 6. 코드로 보기

### 6-1. 지도학습 vs 비지도학습 (같은 데이터, 다른 방식)
```python
# pip install scikit-learn
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.cluster import KMeans
from sklearn.metrics import accuracy_score, adjusted_rand_score

X, y = load_iris(return_X_y=True)          # 붓꽃 150개, 특징 4개, 품종 3종

# ① 지도학습: 정답 y를 보고 학습
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)
clf = KNeighborsClassifier(n_neighbors=5).fit(X_tr, y_tr)
print("지도학습 정확도:", accuracy_score(y_te, clf.predict(X_te)))

# ② 비지도학습: 정답 없이 3그룹으로 묶기
km = KMeans(n_clusters=3, n_init=10, random_state=0).fit(X)
print("군집 결과와 실제 품종의 일치도(ARI):", round(adjusted_rand_score(y, km.labels_), 3))
# 정답을 한 번도 안 봤는데도 품종 구조를 상당 부분 찾아낸다
```

### 6-2. 강화학습 맛보기 — 1차원 길 찾기 Q-Learning
```python
import numpy as np, random

N, GOAL = 6, 5                     # 칸 0~5, 5번 칸에 도착하면 보상 +1
Q = np.zeros((N, 2))               # 상태별 [왼쪽, 오른쪽] 행동 가치
alpha, gamma, eps = 0.5, 0.9, 0.2  # 학습률, 할인율, 탐험 확률

for episode in range(200):
    s = 0
    while s != GOAL:
        a = random.randint(0, 1) if random.random() < eps else int(Q[s].argmax())  # 탐험 vs 활용
        s2 = max(0, s - 1) if a == 0 else min(N - 1, s + 1)
        r = 1.0 if s2 == GOAL else 0.0
        Q[s, a] += alpha * (r + gamma * Q[s2].max() - Q[s, a])   # Q-Learning 업데이트
        s = s2

print(np.round(Q, 2))
print("학습된 정책:", ["←→"[int(q.argmax())] for q in Q[:GOAL]])   # 모두 → 가 나오면 성공
```
정답 행동("오른쪽으로 가라")을 한 번도 알려주지 않았지만, 도착했을 때 받은 보상이 거꾸로 전파되면서 모든 칸에서 "→"를 고르게 됩니다. (Day 053~054에서 자세히)
