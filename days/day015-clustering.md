## 1. 한 줄 요약
**군집화(Clustering)** 는 **정답(라벨) 없이** 데이터만 보고 "비슷한 것끼리 알아서 묶는" **비지도 학습**입니다. **k-means** 는 "묶음을 k개로 정하고, 각 묶음의 **중심점**을 반복해서 옮기며" 나누는 방법이고, **DBSCAN** 은 "점이 **빽빽하게 모인 곳**을 하나의 묶음으로 보고, 동떨어진 점은 **노이즈**로 버리는" 방법입니다. 고객을 비슷한 성향끼리 묶거나, 공장 센서 데이터에서 평소와 다른 이상치를 찾거나, 라이다 점구름에서 물체를 덩어리로 분리할 때 쓰입니다.

```
  [정답 없는 데이터]          [k-means, k=3]             [DBSCAN]
   ·  · ·      · ·            A A A      B B             A A A      B B
  · ·  ·      · · ·          A A  A     B B B           A A  A     B B B
   · ·          ·             A A          B             A A          B
         · · ·                      C C C                      C C C
    ·    · · · ·               A    C C C C               ✕    C C C C    ✕ = 노이즈
        · ·                        C C                        C C
  "누가 같은 편인지 모름"     중심 3개로 나눔           밀집 지역만 묶음
```

## 2. 핵심 용어
| 용어 | 뜻 | 예시 |
|---|---|---|
| 비지도 학습 (Unsupervised Learning) | 정답 라벨 없이 데이터 구조를 찾는 학습 | 군집화, 차원 축소 |
| 군집 (Cluster) | 서로 비슷해서 한 묶음으로 묶인 데이터들 | "자주 오는 단골" 그룹 |
| 중심점 (Centroid) | 한 군집에 속한 점들의 평균 위치 | (지름 평균, 무게 평균) |
| k-means | 중심점 k개를 반복 이동시켜 나누는 알고리즘 | `KMeans(n_clusters=3)` |
| 관성 (Inertia, SSE) | 각 점과 자기 중심점 사이 거리 제곱의 합. 작을수록 촘촘 | `model.inertia_` |
| 엘보 방법 (Elbow Method) | k를 늘려가며 관성이 "꺾이는" 지점을 k로 고름 | k=3에서 팔꿈치 |
| 실루엣 점수 (Silhouette Score) | "내 군집과는 가깝고 남의 군집과는 먼가"를 -1~1로 표시 | 0.7 = 잘 나뉨 |
| k-means++ | 처음 중심점을 서로 멀리 떨어지게 뽑는 초기화 | sklearn 기본값 |
| DBSCAN | 밀도(Density) 기반 군집화. 빽빽한 곳 = 군집 | `DBSCAN(eps=0.3)` |
| eps (ε) | "이웃"으로 볼 반경 | 반경 0.3 |
| min_samples | 핵심점이 되려면 반경 안에 있어야 할 최소 점 수 | 5개 |
| 핵심점 / 경계점 / 노이즈 | 이웃이 충분한 점 / 핵심점 옆에 붙은 점 / 어디에도 못 낀 점 | 라벨 `-1` = 노이즈 |

## 3. 개념과 작동 원리

### 3-1. 지도 학습과 무엇이 다른가
```
 지도 학습 (Day 008~014)                 비지도 학습 (오늘)
 ┌──────────────┬──────┐               ┌──────────────┐
 │ 지름  무게   │ 정답 │               │ 지름  무게   │   ← 정답 칸이 없다
 │  6    4     │ 볼트 │               │  6    4     │
 │ 11   10     │ 너트 │               │ 11   10     │
 └──────────────┴──────┘               └──────────────┘
 "이건 볼트야"를 보고 배운다            "비슷한 것끼리 묶어 봐"만 시킨다
 → 새 데이터의 정답을 맞힘             → 묶음 번호(0, 1, 2…)만 붙여 줌. 이름은 사람이 붙임
```
> 군집화 결과는 "0번 묶음, 1번 묶음"일 뿐입니다. 0번이 볼트인지 너트인지는 사람이 묶음을 들여다보고 해석해야 합니다.

### 3-2. k-means — 4단계를 반복합니다
```
 ① 중심점 k개를 아무 데나(또는 k-means++로) 놓는다
 ② 모든 점을 "가장 가까운 중심점" 편으로 배정한다
 ③ 각 편에 속한 점들의 평균 위치로 중심점을 옮긴다
 ④ 중심점이 더 이상 안 움직일 때까지 ②~③ 반복

  1회차                 2회차                 수렴
   ★A  ·  ·              · · ·                 A A A
  · · ·      ★B        · ★A ·    · ★B         A ★A A    B ★B
   · ·    · · ·         · ·    · · ·           A A    B B B
           · ·                  · ·                    B B
 (중심이 엉뚱한 곳)     (평균으로 이동 중)     (더 안 움직임 → 끝)
```
- **"k-평균"** 이라는 이름 그대로, 중심점 = **평균(mean)** 입니다.
- 반복할수록 **관성(점–중심 거리 제곱합)** 이 줄어들고, 더 이상 안 줄면 멈춥니다.
- 처음 중심을 어디 두느냐에 따라 결과가 달라질 수 있어서, sklearn은 **k-means++** 로 시작점을 고르고 여러 번(`n_init`) 돌려 가장 좋은 결과를 씁니다.

### 3-3. k는 어떻게 정할까 — 엘보와 실루엣
```
 관성                                      실루엣 점수 (클수록 좋음)
  │●                                        │        ●
  │  ●                                      │      ●   ●
  │    ●  ← 팔꿈치(elbow): 여기서 꺾인다        │    ●        ●
  │       ●───●───●───●                    │  ●              ●
  └──────────────────── k                  └──────────────────── k
    1  2  3  4  5  6                          2  3  4  5  6
 k를 늘리면 관성은 무조건 줄어든다           최고점의 k를 고른다
 → "더 늘려도 별 이득 없는 지점"을 고른다
```
| 지표 | 계산 | 해석 |
|---|---|---|
| 관성 (Inertia) | Σ(점과 자기 중심점 거리)² | 작을수록 촘촘하지만, k가 커지면 항상 작아짐 |
| 실루엣 (Silhouette) | (b − a) / max(a, b), a = 내 군집 평균거리, b = 가장 가까운 남 군집 평균거리 | 1에 가까우면 잘 나뉨, 0 근처면 경계, 음수면 잘못 배정 |

### 3-4. k-means가 못 하는 것
k-means는 각 점을 "가장 가까운 중심점"에 붙이기 때문에, 군집 모양이 **둥근 덩어리**라고 가정합니다.
```
 실제 모양: 초승달 두 개             k-means 결과                DBSCAN 결과
     ● ● ● ●                         A A A A                    A A A A
   ●         ●                     A         B                A         A
  ●     ○ ○    ●                  A     A B    B             A     B B    A
         ○      ○                        B      B                   B      B
          ○ ○ ○                           B B B                      B B B
                                  직선으로 반 갈라 버림         모양 따라 정확히 묶음
```
| 상황 | k-means | DBSCAN |
|---|---|---|
| 둥글고 크기 비슷한 군집 | ✅ 잘함 | ✅ 잘함 |
| 초승달·고리처럼 휘어진 모양 | ❌ 직선으로 자름 | ✅ 모양 따라감 |
| 이상치(노이즈) 섞임 | ❌ 억지로 아무 군집에 넣음 (중심이 끌려감) | ✅ 노이즈(-1)로 따로 뺌 |
| 군집 개수를 모름 | ❌ k를 미리 정해야 함 | ✅ 알아서 정해짐 |
| 밀도가 서로 다른 군집 | △ | ❌ eps 하나로 다 맞추기 어려움 |
| 아주 큰 데이터 | ✅ 빠름 | △ 이웃 탐색 비용 |

### 3-5. DBSCAN — 점을 세 종류로 나눕니다
```
 eps = 반경,  min_samples = 4 라고 하면

        ·                ◎ 핵심점(Core): 반경 eps 안에 점이 4개 이상
     ◎ ◎ ◎ ○             ○ 경계점(Border): 이웃은 적지만 핵심점 반경 안에 있음
     ◎ ◎ ◎                ✕ 노이즈(Noise): 어느 핵심점 반경에도 안 들어감
       ◎     ✕
                         ① 핵심점을 하나 잡고
                         ② 반경 안의 핵심점들을 줄줄이 연결해 한 군집으로 확장
                         ③ 경계점은 붙여 주고, 노이즈는 라벨 -1
```
- **eps가 너무 작으면** 다 노이즈가 되고, **너무 크면** 전부 한 군집이 됩니다.
- 거리 기반이므로 Day 014의 k-NN처럼 **스케일링이 필수**입니다.
- eps 고르는 요령: 각 점에서 min_samples번째로 가까운 이웃까지의 거리를 정렬해 그려 보고, 급격히 꺾이는 지점을 eps로 씁니다(k-거리 그래프).

### 3-6. 그 밖의 군집화 방법
| 방법 | 아이디어 | 특징 |
|---|---|---|
| 계층적 군집 (Agglomerative) | 가장 가까운 두 묶음을 계속 합쳐 트리(덴드로그램)를 만듦 | 원하는 높이에서 잘라 군집 수 결정 |
| 가우시안 혼합 (GMM) | 각 군집을 타원형 정규분포로 봄. "이 점이 A일 확률 70%" | 소프트 군집, 타원 모양 가능 |
| HDBSCAN | DBSCAN을 여러 밀도로 확장 | 밀도가 다른 군집도 처리, eps 불필요 |
| Mean Shift | 점들이 밀도가 높은 쪽으로 언덕을 올라가 모임 | 군집 수 자동 |

## 4. 구조 — 두 알고리즘 비교
```
                 k-means                               DBSCAN
 입력       데이터 + k(군집 수)                    데이터 + eps + min_samples
 기억하는 것  중심점 k개 (k × 특성 수 개의 숫자)       모델이라기보다 "라벨 결과" 자체
 새 점 배정   가장 가까운 중심점으로 바로 배정(predict)   predict 없음 (다시 돌리거나 k-NN을 덧붙임)
 비용        반복 × n × k  → 큰 데이터도 빠름        이웃 탐색 n × (이웃 찾기) → 인덱스 필요
 결과        모든 점이 반드시 어느 군집에 들어감       군집 + 노이즈(-1)

 ┌──────────┐   스케일링   ┌────────────┐   라벨 0,1,2…   ┌─────────────┐
 │ 원본 데이터 │ ───────▶  │ 군집화 모델  │ ─────────────▶ │ 사람이 해석   │
 └──────────┘ (필수!)    └────────────┘                └─────────────┘
                                                      "0번 = 소량 다빈도 고객"
```

## 6. 코드로 보기 — 라벨 없는 부품 데이터 묶기

### 6-1. k-means를 직접 구현해 중심이 움직이는 모습 보기
```python
import numpy as np

rng = np.random.default_rng(0)
# 정답은 숨겨 둔 채 세 종류 부품(소·중·대)을 섞는다: [지름(mm), 무게(g)]
X = np.vstack([rng.normal([5, 3], 0.6, (30, 2)),
               rng.normal([9, 8], 0.7, (30, 2)),
               rng.normal([13, 4], 0.6, (30, 2))])

k = 3
centers = X[[0, 1, 2]].copy()          # 일부러 나쁜 시작: 세 중심 모두 첫 번째 무리에서 뽑음
for it in range(10):
    d = np.linalg.norm(X[:, None, :] - centers[None, :, :], axis=2)   # 모든 점–중심 거리
    labels = d.argmin(axis=1)                                         # ② 가장 가까운 중심에 배정
    inertia = (d[np.arange(len(X)), labels] ** 2).sum()
    new = np.array([X[labels == j].mean(axis=0) for j in range(k)])   # ③ 평균으로 이동
    moved = np.linalg.norm(new - centers, axis=1).max()
    print(f"{it+1}회차 중심=" + " ".join(f"({c[0]:5.2f},{c[1]:5.2f})" for c in new)
          + f"  관성={inertia:7.1f}  최대이동={moved:.3f}")
    centers = new
    if moved < 1e-6:
        print("→ 중심이 더 이상 움직이지 않아 종료")
        break
print("군집별 점 개수:", np.bincount(labels))
```

```

2회차 중심=( 5.16, 2.79) (11.00, 6.02) ( 4.85, 3.30)  관성=  579.9  최대이동=0.855
3회차 중심=( 5.02, 2.77) (11.00, 6.02) ( 4.88, 3.36)  관성=  532.0  최대이동=0.142
4회차 중심=( 4.81, 2.72) (11.00, 6.02) ( 5.01, 3.46)  관성=  530.9  최대이동=0.219
5회차 중심=( 4.57, 2.77) (11.00, 6.02) ( 5.25, 3.51)  관성=  528.4  최대이동=0.246
6회차 중심=( 4.58, 2.82) (11.00, 6.02) ( 5.33, 3.55)  관성=  526.1  최대이동=0.096
7회차 중심=( 4.56, 2.89) (11.00, 6.02) ( 5.42, 3.52)  관성=  525.9  최대이동=0.088

```
- 중심이 매 회차 **평균 위치로 이동**하며 관성이 2944.5 → 525.7로 줄고, 8회차에 멈췄습니다.
- 그런데 결과는 **17 / 60 / 13개**입니다. 실제로는 30개씩 세 무리인데, 시작 중심 셋을 모두 한 무리에서 뽑았더니 중심 둘이 작은 부품 무리를 나눠 갖고 나머지 하나가 중·대형 60개를 다 떠안았습니다. 이렇게 **더 나아질 수 있는데도 멈추는 상태**를 **지역 최적해(local optimum)** 라고 합니다.
- 같은 데이터를 k-means++ 초기화로 돌린 다음 코드(6-2)의 k=3 관성은 **67.2**입니다. 시작점이 결과를 얼마나 바꾸는지 보여 줍니다. 그래서 실무에서는 k-means++ + 여러 번 시작(`n_init`)을 씁니다.

### 6-2. 엘보와 실루엣으로 k 고르기
```python
import numpy as np
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

rng = np.random.default_rng(0)
X = np.vstack([rng.normal([5, 3], 0.6, (30, 2)),
               rng.normal([9, 8], 0.7, (30, 2)),
               rng.normal([13, 4], 0.6, (30, 2))])

print(" k     관성     실루엣")
for k in range(1, 7):
    m = KMeans(n_clusters=k, n_init=10, random_state=0).fit(X)
    sil = silhouette_score(X, m.labels_) if k > 1 else float("nan")
    bar = "█" * round(m.inertia_ / 40)
    print(f" {k}  {m.inertia_:7.1f}   {sil:5.2f}   {bar}")
```
실행 결과
```
 k     관성     실루엣
 1   1434.1     nan   ████████████████████████████████████
 2    534.1    0.63   █████████████
 3     67.2    0.81   ██
 4     52.9    0.68   █
 5     44.1    0.54   █
 6     35.7    0.40   █
```
- 관성은 k=2 → 3에서 534.1 → 67.2로 뚝 떨어지고, 그 뒤로는 조금씩만 줄어듭니다. **팔꿈치 = k=3**.
- 실루엣 점수도 **k=3에서 0.81로 최고**입니다. 두 지표 모두 숨겨 둔 정답(세 종류)을 찾아냈습니다.

### 6-3. 초승달 + 노이즈: k-means vs DBSCAN
```python
import numpy as np
from sklearn.datasets import make_moons
from sklearn.cluster import KMeans, DBSCAN
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import adjusted_rand_score

X, y = make_moons(n_samples=300, noise=0.06, random_state=0)
rng = np.random.default_rng(1)
outliers = rng.uniform([-1.5, -1.0], [2.5, 1.5], (12, 2))     # 엉뚱한 곳에 흩뿌린 이상치 12개
X_all = np.vstack([X, outliers])
Xs = StandardScaler().fit_transform(X_all)

km = KMeans(n_clusters=2, n_init=10, random_state=0).fit_predict(Xs)
db = DBSCAN(eps=0.3, min_samples=5).fit_predict(Xs)

# ARI: 정답(초승달 2개)과 얼마나 일치하는지 (1 = 완벽, 0 = 무작위 수준). 정답 있는 300개만 비교
print(f"k-means 정답 일치도(ARI): {adjusted_rand_score(y, km[:300]):.2f}")
print(f"DBSCAN  정답 일치도(ARI): {adjusted_rand_score(y, db[:300]):.2f}")
print(f"DBSCAN 군집 수: {len(set(db)) - (1 if -1 in db else 0)}, 노이즈로 뺀 점: {(db == -1).sum()}개"
      f" (이상치 12개 중 {(db[300:] == -1).sum()}개 적중)")

def draw(labels, title):
    sym = {0: "A", 1: "B", -1: "✕"}
    grid = [[" "] * 44 for _ in range(12)]
    for (x1, x2), l in zip(X_all, labels):
        c = int((x1 + 1.5) / 4.0 * 43); r = int((1.5 - x2) / 2.5 * 11)
        if 0 <= r < 12 and 0 <= c < 44:
            grid[r][c] = sym.get(l, "?")
    print(f"\n[{title}]")
    for row in grid:
        print("  " + "".join(row))

draw(km, "k-means (k=2)")
draw(db, "DBSCAN (eps=0.3)")
```
