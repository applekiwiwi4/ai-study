> 📅 2026-11-17 · 1부. 기초 개념 · ⏱ 예상 학습 시간 40~50분

## 1. 한 줄 요약
**미분**은 "입력을 아주 조금 바꾸면 출력이 얼마나 바뀌나?"를 알려 줍니다. 입력이 여러 개일 때 각 방향의 미분을 모아 놓은 벡터가 **그래디언트**이고, 그래디언트의 **반대 방향**으로 조금씩 내려가는 것이 Day 004의 **경사하강법**입니다. **확률**은 "얼마나 그럴듯한가"를 0~1 숫자로 나타내며, 모델이 내놓는 "안전모 미착용 확률 93%" 같은 답이 바로 확률입니다.

```
  미분 = 기울기                     그래디언트 = 가장 가파르게 올라가는 방향
                                       ↑ 반대로 가면 = 가장 빨리 내려감 (학습)
  손실                                
   │\                                  ┌──────────────┐
   │ \  ← 여기서 기울기 = -2              │   ╭──────╮   │
   │  \     (오른쪽으로 가면 줄어듦)       │  ╭╯ ╭──╮ ╰╮  │  등고선 지도
   │   \___/                           │  │  │● │  │  │   ●=최저점
   │     ↑ 기울기 = 0 (최저점)           │  ╰╮ ╰──╯ ╭╯  │
   └──────────── w                     │   ╰──────╯   │
                                       └──────────────┘
```

## 2. 핵심 용어
| 용어 | 뜻 | 예시 |
|---|---|---|
| 함수 (Function) | 입력을 넣으면 출력이 나오는 규칙 | `손실 = f(가중치)` |
| 미분 / 도함수 (Derivative) | 입력이 아주 조금 변할 때 출력의 변화 비율 = 그래프의 기울기 | `f(x) = x²`의 미분은 `2x` |
| 기울기 (Slope) | 한 지점에서의 미분값. 양수면 오르막, 음수면 내리막 | x=3에서 6 |
| 편미분 (Partial Derivative) | 입력이 여러 개일 때 **하나만** 바꾸고 나머지는 고정한 미분 | `∂L/∂w` |
| 그래디언트 (Gradient) | 모든 편미분을 모은 벡터. 기호 `∇` | `∇L = [∂L/∂w, ∂L/∂b]` |
| 연쇄 법칙 (Chain Rule) | 함수가 겹쳐 있을 때 미분끼리 곱해서 구하는 규칙 | 역전파의 핵심 (Day 019) |
| 확률 (Probability) | 어떤 일이 일어날 가능성. 0(불가능) ~ 1(확실) | 동전 앞면 0.5 |
| 조건부 확률 (Conditional) | "B가 일어났을 때" A의 확률. `P(A|B)` | 경보가 울렸을 때 진짜 불량일 확률 |
| 베이즈 정리 (Bayes) | 새 증거를 보고 확률을 고쳐 계산하는 공식 | 스팸 필터, 센서 융합 |
| 확률 분포 (Distribution) | 가능한 모든 결과와 각각의 확률 | 주사위: 1~6 각 1/6 |
| 정규분포 (Normal / Gaussian) | 평균 근처에 많고 멀어질수록 적은 종 모양 분포 | 키, 센서 노이즈 |
| 기댓값 (Expectation) | 확률로 가중한 평균 | 주사위 기댓값 3.5 |

## 3. 개념과 작동 원리

### 3-1. 미분 — "조금 바꾸면 얼마나 바뀌나"
자동차로 비유하면 **위치를 미분한 것이 속도**입니다. "1초 동안 몇 m 움직였나"가 변화율이죠.

`f(x) = x²` 에서 x=3 근처를 아주 조금(h = 0.001) 움직여 봅니다.
```
 f(3)     = 9
 f(3.001) = 9.006001
 변화율 = (9.006001 - 9) / 0.001 ≈ 6.0   ← 이것이 x=3에서의 미분(기울기)

 공식으로: f(x) = x² 의 미분 = 2x  →  x=3 이면 2×3 = 6 ✔
```

| 함수 | 미분 | 외울 필요 없이 의미만 |
|---|---|---|
| `c` (상수) | 0 | 변하지 않으니 변화율 0 |
| `x` | 1 | x가 1 늘면 1 늘어남 |
| `x²` | `2x` | 멀어질수록 빨리 커짐 |
| `a·x + b` | `a` | 직선의 기울기 = a |
| `eˣ` | `eˣ` | 자기 자신 |

**기울기의 부호가 학습 방향을 알려 줍니다.**
```
 손실
  │ \                         /
  │  \  기울기 < 0           /  기울기 > 0
  │   \ → w를 키워라        /   → w를 줄여라
  │    \                  /
  │     \______●_______/
  │          최저점 (기울기 = 0)
  └────────────────────────── w
 규칙: w_new = w - 학습률 × 기울기   (기울기 반대 방향으로 이동)
```

### 3-2. 편미분과 그래디언트 — 손잡이가 여러 개일 때
모델에는 가중치가 수백만 개 있습니다. 손잡이(가중치)를 **하나씩만 살짝 돌려 보고** 손실이 얼마나 변하는지 재는 것이 편미분입니다.

```
 손실 L(w, b) = (w - 3)² + (b + 1)²        최저점: w=3, b=-1

 ∂L/∂w = 2(w - 3)    ← b는 고정, w만 움직였을 때 기울기
 ∂L/∂b = 2(b + 1)    ← w는 고정, b만 움직였을 때 기울기

 그래디언트 ∇L = [ 2(w-3), 2(b+1) ]

 (w, b) = (0, 0) 에서:  ∇L = [-6, 2]
   → "w 방향으로는 가파른 내리막(-6), b 방향으로는 오르막(+2)"
   → 반대 방향 [+6, -2]로 가면 손실이 가장 빨리 줄어든다
```

**그래디언트를 지도 위 화살표로 보면**
```
  b
  2 │  ↘  ↘  ↓  ↙  ↙        화살표 = -∇L (내려가는 방향)
  1 │  ↘  ↘  ↓  ↙  ↙        모든 화살표가 최저점 ● 을 향함
  0 │  ↘  ↘  ↓  ↙  ↙
 -1 │  →  → [●] ←  ←
 -2 │  ↗  ↗  ↑  ↖  ↖
    └──────────────── w
       1  2  3  4  5
```

### 3-3. 경사하강법 다시 보기 (Day 004 연결)
```
 ① 현재 가중치에서 그래디언트 계산    ∇L
 ② 반대 방향으로 한 걸음             w ← w - η·∇L   (η = 학습률)
 ③ 손실이 충분히 작아질 때까지 반복

  학습률이 너무 작으면 → 거북이처럼 느림     ●·····→·····→·····→
  학습률이 적당하면   → 빠르게 도착          ●──→──→●
  학습률이 너무 크면  → 왔다 갔다 튀어 나감   ●↘   ↗↘   ↗ (발산)
```

### 3-4. 연쇄 법칙 — 신경망이 그래디언트를 구하는 방법 (맛보기)
신경망은 함수를 여러 겹 쌓은 것입니다. 겹친 함수의 미분은 **각 단계의 미분을 곱하면** 됩니다.
```
 x ──[×3]──▶ u ──[제곱]──▶ y            y = (3x)²
        du/dx = 3     dy/du = 2u

 dy/dx = dy/du × du/dx = 2u × 3 = 6u = 18x
 x = 1 이면 18
```
출력 쪽에서 입력 쪽으로 미분을 곱해 가며 거꾸로 전달하는 것이 **역전파(Backpropagation, Day 019)** 이고, PyTorch는 이걸 `loss.backward()` 한 줄로 자동 계산합니다.

### 3-5. 확률 기초
| 개념 | 설명 | 예시 |
|---|---|---|
| 확률 범위 | 0 ≤ P ≤ 1, 모든 경우의 합 = 1 | 주사위 1~6 각각 1/6, 합 = 1 |
| 여사건 | 일어나지 **않을** 확률 = 1 - P | 비가 올 확률 0.3 → 안 올 확률 0.7 |
| 독립 사건의 곱 | 둘 다 일어날 확률 = P(A) × P(B) | 동전 두 번 앞면 = 0.5 × 0.5 = 0.25 |
| 조건부 확률 | P(A|B) = P(A와 B) / P(B) | 아래 베이즈 예시 |

**모델 출력이 확률이 되는 과정 — Softmax**
```
 신경망 출력(점수)     →    Softmax    →    확률
 착용   : 1.0                               0.11
 미착용 : 3.0                               0.82   ← 가장 높음 = 예측 결과
 사람아님: 0.5                               0.07
                                    합 = 1.00
 Softmax = 각 점수에 eˣ를 취한 뒤 전체 합으로 나눔 → 모두 양수, 합은 1
```

### 3-6. 베이즈 정리 — "경보가 울렸으면 진짜 불량일까?"
불량률이 1%인 공장에 검사 AI가 있습니다. 이 AI는 진짜 불량의 95%를 잡아내지만(재현율 95%), 정상품도 5%는 불량이라고 잘못 경보를 냅니다.

**경보가 울렸을 때 진짜 불량일 확률은? → 95%가 아닙니다!**
```
 제품 10,000개 기준
 ├─ 불량 100개 (1%)
 │    ├─ 경보 O : 95개   ✅ 진짜 불량 (TP)
 │    └─ 경보 X :  5개
 └─ 정상 9,900개 (99%)
      ├─ 경보 O : 495개  ❌ 거짓 경보 (FP)
      └─ 경보 X : 9,405개

 경보가 울린 제품 = 95 + 495 = 590개
 그중 진짜 불량    = 95개
 P(불량 | 경보) = 95 / 590 ≈ 0.161  →  약 16%
```
> Day 006의 **정밀도**가 바로 이 값입니다. 불량 자체가 드물면(사전 확률이 낮으면) 성능 좋은 모델도 경보의 대부분이 거짓일 수 있습니다. 베이즈 정리는 이것을 공식으로 정리한 것입니다.
>
> `P(불량|경보) = P(경보|불량) × P(불량) / P(경보) = 0.95 × 0.01 / 0.059 ≈ 0.161`

### 3-7. 정규분포 — 세상의 노이즈 모양
```
 개수
  │            ▄█▄
  │          ▄█████▄
  │        ▄█████████▄          평균(μ) 근처에 대부분 몰려 있음
  │     ▄▄███████████████▄▄       ±1σ 안에 약 68%
  │▁▁▄▄█████████████████████▄▄▁▁   ±2σ 안에 약 95%
  └──────────────┬───────────────
               평균 μ
```
- 센서 노이즈, 측정 오차, 사람의 키가 이런 모양을 따릅니다.
- 신경망 가중치를 **처음 만들 때** 정규분포에서 무작위로 뽑습니다 (Day 022).
- 데이터 정규화(Day 002)의 `(x - 평균) / 표준편차`는 이 분포를 평균 0, 표준편차 1로 맞추는 작업입니다.

## 6. 코드로 보기

### 6-1. 미분을 숫자로 직접 계산하기
```python
def f(x):
    return x ** 2

def numerical_derivative(func, x, h=1e-5):
    return (func(x + h) - func(x - h)) / (2 * h)   # 양쪽으로 살짝 움직여 기울기 측정

for x in [-2, 0, 3]:
    print(f"x={x:>2}  f(x)={f(x):>2}  기울기≈{numerical_derivative(f, x):.4f}  공식 2x={2*x}")
```
실행 결과
```
x=-2  f(x)= 4  기울기≈-4.0000  공식 2x=-4
x= 0  f(x)= 0  기울기≈0.0000  공식 2x=0
x= 3  f(x)= 9  기울기≈6.0000  공식 2x=6
```

### 6-2. 그래디언트로 최저점 찾아가기 (경로를 눈으로 확인)
```python
import numpy as np

def loss(w, b):
    return (w - 3) ** 2 + (b + 1) ** 2         # 최저점 (3, -1)

def grad(w, b):
    return np.array([2 * (w - 3), 2 * (b + 1)])

p = np.array([0.0, 2.0])                         # 출발점 (w=0, b=2)
lr = 0.2
path = [p.copy()]
for step in range(8):
    g = grad(*p)
    p = p - lr * g                               # 그래디언트 반대 방향으로 이동
    path.append(p.copy())
    print(f"step {step+1}: w={p[0]:5.2f}  b={p[1]:5.2f}  손실={loss(*p):.4f}")

# 지도에 경로 그리기 (가로 w: 0~4, 세로 b: 2~-1)
grid = [["·"] * 9 for _ in range(7)]
for i, (w, b) in enumerate(path):
    col, row = round(w * 2), round((2 - b) * 2)
    if 0 <= row < 7 and 0 <= col < 9:
        grid[row][col] = "S" if i == 0 else "o"
grid[round((2 - (-1)) * 2)][round(3 * 2)] = "★"     # 최저점
print("\n b↓  w→ 0   1   2   3   4")
for r, line in enumerate(grid):
    print(f"{2 - r/2:5.1f} " + " ".join(line))
```
실행 결과
```
step 1: w= 1.20  b= 0.80  손실=6.4800
step 2: w= 1.92  b= 0.08  손실=2.3328
step 3: w= 2.35  b=-0.35  손실=0.8398
step 4: w= 2.61  b=-0.61  손실=0.3023
step 5: w= 2.77  b=-0.77  손실=0.1088
step 6: w= 2.86  b=-0.86  손실=0.0392
step 7: w= 2.92  b=-0.92  손실=0.0141
step 8: w= 2.95  b=-0.95  손실=0.0051

 b↓  w→ 0   1   2   3   4
  2.0 S · · · · · · · ·
  1.5 · · · · · · · · ·
  1.0 · · o · · · · · ·
  0.5 · · · · · · · · ·
  0.0 · · · · o · · · ·
 -0.5 · · · · · o · · ·
 -1.0 · · · · · · ★ · ·
```
S(출발)에서 ★(최저점)으로 갈수록 손실이 줄고, 가까워질수록 기울기가 작아져서 **걸음이 점점 짧아지는** 것을 볼 수 있습니다.

### 6-3. 학습률에 따른 차이
```python
def run(lr, steps=6):
    w = 0.0
    trace = []
    for _ in range(steps):
        w = w - lr * 2 * (w - 3)                 # L = (w-3)², 최저점 w=3
        trace.append(f"{w:6.2f}")
    return " → ".join(trace)

for lr in [0.05, 0.4, 1.05]:
    print(f"학습률 {lr:<4}: {run(lr)}")
```
실행 결과
```
학습률 0.05:   0.30 →   0.57 →   0.81 →   1.03 →   1.23 →   1.41
학습률 0.4 :   2.40 →   2.88 →   2.98 →   3.00 →   3.00 →   3.00
학습률 1.05:   6.30 →  -0.63 →   6.99 →  -1.39 →   7.83 →  -2.31
```
0.05는 너무 느리고, 0.4는 빠르게 3에 도착하고, 1.05는 3을 지나쳐 점점 더 멀어집니다(**발산**).

### 6-4. 확률: 주사위 시뮬레이션, Softmax, 베이즈
```python
import numpy as np
rng = np.random.default_rng(42)

# (1) 주사위 6,000번 → 각 눈이 약 1/6씩 나오는지 막대로 확인
rolls = rng.integers(1, 7, size=6000)
print("주사위 6,000번")
for face in range(1, 7):
    cnt = (rolls == face).sum()
    print(f"  {face}: {'█' * (cnt // 50)} {cnt}  ({cnt/6000:.3f})")
print(f"  평균(기댓값 3.5에 가까운가?): {rolls.mean():.3f}")

# (2) Softmax: 점수 → 확률
scores = np.array([1.0, 3.0, 0.5])
probs = np.exp(scores) / np.exp(scores).sum()
for name, p in zip(["착용", "미착용", "사람아님"], probs):
    print(f"  {name:<5} {p:.2f}")
print("  확률 합:", round(probs.sum(), 2))

# (3) 베이즈: 경보가 울렸을 때 진짜 불량일 확률
p_defect, recall, false_alarm = 0.01, 0.95, 0.05
p_alarm = recall * p_defect + false_alarm * (1 - p_defect)
print(f"\nP(불량 | 경보) = {recall * p_defect / p_alarm:.3f}")
```
