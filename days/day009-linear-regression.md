# Day 009 — 선형 회귀와 경사하강법

> 📅 2026-11-18 · 2부. 고전 머신러닝 · ⏱ 예상 학습 시간 40~50분

## 1. 한 줄 요약
**선형 회귀(Linear Regression)** 는 데이터에 가장 잘 맞는 **직선(또는 평면)** 을 찾아 숫자를 예측하는 가장 기본적인 머신러닝 모델입니다. "가장 잘 맞는다"는 **MSE(평균제곱오차)가 가장 작다**는 뜻이고, 그 직선의 기울기 `w`와 절편 `b`를 Day 008의 **그래디언트로 조금씩 고쳐 가며** 찾는 것이 경사하강법입니다. 딥러닝의 한 층(`y = Wx + b`)도 결국 선형 회귀를 여러 개 겹친 것이라 모든 모델의 출발점입니다.

```
 실제 거리(mm)                              예측 직선 ŷ = w·x + b
   │                               ●     ╱
   │                          ●      ╱
   │                     ●  ↕오차 ╱  ●
   │                ●       ╱
   │           ●      ╱  ●            목표: 모든 점의 오차² 평균(MSE)이
   │      ●     ╱                          가장 작아지는 w, b 찾기
   │  ●   ╱ ●
   └───────────────────────────── 카메라 픽셀 좌표 x
```

## 2. 핵심 용어
| 용어 | 뜻 | 예시 |
|---|---|---|
| 회귀 (Regression) | 연속적인 **숫자**를 예측하는 문제 | 집값, 거리, 온도 |
| 선형 (Linear) | 입력에 가중치를 곱해 더하기만 하는 관계 (직선·평면) | `ŷ = 2x + 1` |
| 가중치 / 기울기 `w` (Weight) | 입력이 1 늘 때 출력이 얼마나 늘어나는지 | 픽셀 1개 = 0.5mm |
| 편향 / 절편 `b` (Bias) | 입력이 0일 때의 출력 | 원점 위치 보정값 |
| 가설 (Hypothesis) | 모델이 정한 예측 공식 | `ŷ = w·x + b` |
| 잔차 (Residual) | 실제값 - 예측값 | 점과 직선 사이의 세로 거리 |
| MSE (Mean Squared Error) | 잔차를 제곱해서 평균 낸 값 = 손실 함수 | Day 006 회귀 지표 |
| 경사하강법 (Gradient Descent) | 손실의 그래디언트 반대 방향으로 w, b를 고치는 방법 | Day 004, 008 |
| 에폭 (Epoch) | 전체 데이터를 한 번 다 보고 학습한 횟수 | 500 에폭 |
| 정규 방정식 (Normal Equation) | 반복 없이 공식 한 번으로 최적 w, b를 구하는 방법 | 데이터가 작을 때 |
| 다중 선형 회귀 (Multiple) | 입력이 여러 개인 선형 회귀 | 면적·방 수·역 거리 → 집값 |
| 특성 스케일링 (Feature Scaling) | 입력들의 크기 범위를 비슷하게 맞추는 것 | 표준화 (Day 002) |

## 3. 개념과 작동 원리

### 3-1. 모델: 직선 하나
```
 ŷ = w · x + b

   w (기울기)  : 직선이 얼마나 가파른가      b (절편) : 직선이 위아래로 어디에 있나
   w=2  ╱                                    b=+3 ───────────
   w=1 ╱                                     b= 0 ───────────
   w=0 ───────                               b=-3 ───────────
```
- 학습할 숫자는 **w와 b 단 두 개**입니다. 이 두 숫자를 찾으면 모델 완성입니다.

### 3-2. 손실: MSE로 "얼마나 틀렸나" 재기
데이터 3개로 손으로 계산해 봅니다. 현재 모델이 `w=1, b=0`(즉 `ŷ = x`)이라면
| x | 실제 y | 예측 ŷ = x | 잔차 y-ŷ | 잔차² |
|---|---|---|---|---|
| 1 | 3 | 1 | 2 | 4 |
| 2 | 5 | 2 | 3 | 9 |
| 3 | 7 | 3 | 4 | 16 |
| | | | **평균(MSE)** | **29 / 3 ≈ 9.67** |

정답 직선은 `y = 2x + 1`(MSE = 0)입니다. 경사하강법은 w=1, b=0에서 출발해 w=2, b=1로 **스스로** 찾아갑니다.

**왜 그냥 더하지 않고 제곱할까?**
- 잔차 +3과 -3이 더해져 0이 되는 것을 막습니다 (항상 양수).
- 큰 오차를 더 크게 벌줍니다 (3 → 9, 10 → 100).
- 미분하기 쉬운 매끈한 그릇 모양이 됩니다 → 경사하강법이 잘 작동합니다.

### 3-3. 그래디언트: w와 b를 어느 쪽으로 고칠까
MSE를 w와 b로 각각 편미분하면 (Day 008)
```
 L(w, b) = (1/n) Σ (ŷᵢ - yᵢ)²       ŷᵢ = w·xᵢ + b

 ∂L/∂w = (2/n) Σ (ŷᵢ - yᵢ) · xᵢ     ← 오차 × 입력
 ∂L/∂b = (2/n) Σ (ŷᵢ - yᵢ)          ← 오차의 평균

 위 표(w=1, b=0)에서:  ŷ - y = [-2, -3, -4]
   ∂L/∂w = (2/3)(-2·1 - 3·2 - 4·3) = (2/3)(-20) ≈ -13.3   → 음수: w를 키워라
   ∂L/∂b = (2/3)(-2 - 3 - 4)       = (2/3)(-9)  = -6.0    → 음수: b를 키워라
```
> 직관: 예측이 실제보다 **작으면**(ŷ - y < 0) 그래디언트가 음수 → w, b를 **키웁니다**. 크면 줄입니다.

### 3-4. 학습 한 바퀴
```
 ┌──────────────────────────────────────────────────────────────┐
 │ ① 예측       ŷ = w·x + b                                      │
 │ ② 오차       e = ŷ - y                                        │
 │ ③ 손실       L = mean(e²)                                     │
 │ ④ 그래디언트  dw = 2·mean(e·x),  db = 2·mean(e)                 │
 │ ⑤ 수정       w ← w - η·dw,      b ← b - η·db    (η = 학습률)   │
 └──────────────────────── 손실이 충분히 작아질 때까지 반복 ────────┘

 에폭이 진행될수록 직선이 점들 사이로 자리 잡아 감
  에폭 0   ───────────        (엉뚱한 곳)
  에폭 10      ╱ (조금 기울어짐)
  에폭 100       ╱  ● ●       (점들 사이로)
               ● ╱ ●
```

### 3-5. 정규 방정식 — 한 번에 푸는 공식
선형 회귀는 특별히 **공식으로 정답을 바로** 구할 수 있습니다.
```
 θ = (XᵀX)⁻¹ Xᵀ y        (θ = [b, w], X = 입력 앞에 1을 붙인 행렬)
```
| | 경사하강법 | 정규 방정식 |
|---|---|---|
| 방식 | 조금씩 반복해서 접근 | 행렬 계산 한 번 |
| 학습률 | 정해야 함 | 필요 없음 |
| 데이터·특성이 아주 많을 때 | 잘 작동 | 역행렬 계산이 너무 느림 |
| 딥러닝에 쓰이나 | ✅ (모든 신경망) | ❌ (선형 모델만 가능) |

> 그래서 실무 라이브러리(scikit-learn `LinearRegression`)는 공식 방식으로 풀고, 딥러닝은 경사하강법을 씁니다. 두 방법의 답이 같은지 6-3 코드에서 확인합니다.

### 3-6. 다중 선형 회귀와 스케일링
입력이 여러 개면 직선이 아니라 **평면(초평면)** 이 됩니다. Day 007의 행렬 곱으로 한 번에 계산합니다.
```
 ŷ = w₁·면적 + w₂·방 수 + w₃·역까지 거리 + b   =   X · w + b
```
**입력 크기가 제각각이면 경사하강이 지그재그로 느려집니다.**
```
 면적 20~150, 방 수 1~5 처럼 범위가 다르면          표준화(평균0, 표준편차1) 후
   손실 등고선이 길쭉한 타원                          손실 등고선이 둥근 원
   ┌────────────────────┐                          ┌──────────┐
   │ ╭────────────────╮ │  ●↘↗↘↗↘↗→★              │  ╭────╮  │  ●──→★
   │ ╰────────────────╯ │  (지그재그)               │  ╰────╯  │  (곧장)
   └────────────────────┘                          └──────────┘
```

### 3-7. 선형 회귀의 한계
| 한계 | 예 | 해결 방향 |
|---|---|---|
| 곡선 관계를 못 잡음 | 렌즈 왜곡처럼 가장자리로 갈수록 휘는 관계 | 다항 특성 추가 (Day 005), 신경망 (Day 017) |

## 4. 구조 — 선형 회귀 = 뉴런 하나
```
   입력           가중치          합산            출력
   x₁ ───── w₁ ──╮
   x₂ ───── w₂ ──┼──▶ ( Σ + b ) ──────────▶ ŷ      (활성화 함수 없음)
   x₃ ───── w₃ ──╯

  선형 회귀       = 뉴런 1개, 활성화 없음, 손실 MSE
  로지스틱 회귀    = 뉴런 1개 + Sigmoid, 손실 교차 엔트로피 (Day 010)
  신경망(MLP)     = 이런 뉴런을 여러 층 쌓고 사이에 ReLU (Day 017)
```

## 6. 코드로 보기 — 카메라 픽셀 → 실제 거리(mm) 보정

상황: 카메라 화면의 x 픽셀 좌표와 자로 잰 실제 위치(mm)를 10쌍 측정했습니다. 실제 관계는 `mm = 0.5 × 픽셀 + 20`이지만, 측정에 약간의 노이즈가 섞여 있습니다.

### 6-1. 경사하강법을 직접 구현하기
```python
import numpy as np
rng = np.random.default_rng(0)

px = np.linspace(0, 600, 10)                        # 픽셀 좌표 10개
mm = 0.5 * px + 20 + rng.normal(0, 5, size=10)      # 실제 거리(mm) + 측정 노이즈

x = (px - px.mean()) / px.std()                     # 표준화 (스케일링)
w, b, lr = 0.0, 0.0, 0.1
history = []
for epoch in range(101):
    y_hat = w * x + b                               # ① 예측
    err = y_hat - mm                                # ② 오차
    loss = np.mean(err ** 2)                        # ③ 손실 (MSE)
    dw, db = 2 * np.mean(err * x), 2 * np.mean(err) # ④ 그래디언트
    w, b = w - lr * dw, b - lr * db                 # ⑤ 수정
    history.append(loss)
    if epoch in (0, 5, 10, 20, 50, 100):
        print(f"epoch {epoch:>3}  손실 {loss:10.2f}  {'█' * min(40, int(loss // 500))}")

# 표준화 공간의 w, b → 원래 픽셀 단위로 되돌리기
w_px = w / px.std()
b_px = b - w * px.mean() / px.std()
print(f"\n학습 결과: mm = {w_px:.3f} × 픽셀 + {b_px:.2f}   (정답: 0.5 × 픽셀 + 20)")
```
실행 결과
```
epoch   0  손실   38049.64  ████████████████████████████████████████
epoch   5  손실    4097.07  ████████
epoch  10  손실     451.44  
epoch  20  손실      17.96  
epoch  50  손실      12.90  
epoch 100  손실      12.90  

학습 결과: mm = 0.495 × 픽셀 + 21.85   (정답: 0.5 × 픽셀 + 20)
```
손실 막대가 에폭이 지날수록 짧아지고, 학습된 공식이 정답(0.5, 20)에 가까워집니다. 손실이 0이 되지 않는 것은 측정 노이즈 때문이며 정상입니다.

### 6-2. 데이터와 학습된 직선을 그림으로 보기
```python
import numpy as np
rng = np.random.default_rng(0)
px = np.linspace(0, 600, 10)
mm = 0.5 * px + 20 + rng.normal(0, 5, size=10)
w_px, b_px = np.polyfit(px, mm, 1)                  # 같은 직선을 빠르게 구함

H, W = 12, 41                                       # 글자 그림 크기
grid = [[" "] * W for _ in range(H)]
y_min, y_max = 0, 340
to_row = lambda v: H - 1 - int((v - y_min) / (y_max - y_min) * (H - 1))
for c in range(W):                                  # 직선 그리기
    p = c / (W - 1) * 600
    r = to_row(w_px * p + b_px)
    if 0 <= r < H:
        grid[r][c] = "·"
for p, m in zip(px, mm):                            # 측정점 그리기
    grid[to_row(m)][int(p / 600 * (W - 1))] = "●"

print("mm")
for r, line in enumerate(grid):
    label = int(y_max - r * (y_max - y_min) / (H - 1))
    print(f"{label:>4} │" + "".join(line))
print("     └" + "─" * W + " 픽셀")
print("      0" + " " * 17 + "300" + " " * 17 + "600")
```

### 6-3. scikit-learn과 정규 방정식으로 검증하고 새 좌표 예측하기
```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, r2_score

rng = np.random.default_rng(0)
px = np.linspace(0, 600, 10)
mm = 0.5 * px + 20 + rng.normal(0, 5, size=10)

# (1) 정규 방정식: θ = (XᵀX)⁻¹ Xᵀ y
X = np.column_stack([np.ones_like(px), px])         # [1, 픽셀]
theta = np.linalg.inv(X.T @ X) @ X.T @ mm
print(f"정규 방정식   : w={theta[1]:.4f}, b={theta[0]:.3f}")

# (2) scikit-learn
model = LinearRegression().fit(px.reshape(-1, 1), mm)
print(f"scikit-learn : w={model.coef_[0]:.4f}, b={model.intercept_:.3f}")

pred = model.predict(px.reshape(-1, 1))
print(f"MAE={mean_absolute_error(mm, pred):.2f}mm   R²={r2_score(mm, pred):.4f}")

# (3) 새 픽셀 좌표의 실제 위치 예측
for p in [150, 420]:
    print(f"픽셀 {p} → 약 {model.predict([[p]])[0]:.1f} mm")
```
실행 결과
```
정규 방정식   : w=0.4952, b=21.854
scikit-learn : w=0.4952, b=21.854
MAE=3.04mm   R²=0.9986
픽셀 150 → 약 96.1 mm
픽셀 420 → 약 229.9 mm
```
세 방법(직접 구현한 경사하강법, 정규 방정식, scikit-learn) 모두 **같은 직선**을 찾았습니다. 평균 오차가 몇 mm 수준이고 R²가 1에 가까우니 보정이 잘 된 것입니다 (Day 006 지표).

5. 신경망은 비선형이라 공식 해가 없고, 데이터·가중치가 매우 많으면 역행렬 계산이 불가능할 만큼 느리기 때문이다.
6. 손실 등고선이 길쭉한 타원에서 둥근 모양에 가까워져 지그재그 없이 최저점으로 곧장 내려가기 때문이다.
7. 출력이 0~1 확률이 아닌 아무 숫자나 나오고, 범주 경계를 잘 표현하지 못한다. 로지스틱 회귀(Day 010)를 쓴다.
</details>
