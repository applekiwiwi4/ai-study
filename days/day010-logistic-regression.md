# Day 010 — 로지스틱 회귀와 분류

> 📅 2026-11-19 · 2부. 고전 머신러닝 · ⏱ 예상 학습 시간 40~50분

## 1. 한 줄 요약
**로지스틱 회귀(Logistic Regression)** 는 이름에 "회귀"가 붙어 있지만 **분류** 모델입니다. Day 009의 직선 `z = w·x + b`를 **시그모이드(Sigmoid)** 함수에 통과시켜 0~1 사이 **확률**로 바꾸고, 확률이 0.5(임계값) 이상이면 "예", 아니면 "아니오"라고 답합니다. 손실은 MSE 대신 **교차 엔트로피(Cross-Entropy)** 를 쓰고, 학습은 똑같이 경사하강법으로 합니다. 신경망 분류기의 맨 마지막 층이 바로 이 구조입니다.

```
  선형 회귀 (Day 009)                    로지스틱 회귀 (오늘)
  z = w·x + b  →  아무 숫자            z = w·x + b  →  σ(z)  →  0~1 확률  →  0.5 기준으로 판정
  "거리는 229.9mm"                     "안전모 착용 확률 0.87 → 착용"

  확률 σ(z)
   1.0 ┤                    ●●●●●●●  ← 착용(1)
       │                ╭─────────
   0.5 ┤- - - - - - - -╳- - - - - -  ← 임계값 (결정 경계)
       │      ─────────╯
   0.0 ┤●●●●●●●                      ← 미착용(0)
       └───────────────┼──────────── z
                       0
```

## 2. 핵심 용어
| 용어 | 뜻 | 예시 |
|---|---|---|
| 분류 (Classification) | 정해진 **범주** 중 하나를 고르는 문제 | 착용/미착용, 정상/불량 |
| 이진 분류 (Binary) | 범주가 2개인 분류. 정답을 1(양성)과 0(음성)으로 표현 | 스팸/정상 메일 |
| 다중 분류 (Multi-class) | 범주가 3개 이상 | 숫자 0~9, 사과/배/귤 |
| 로짓 (Logit) `z` | 시그모이드에 들어가기 전의 점수 `w·x + b` | z = 2.0 |
| 시그모이드 (Sigmoid) `σ` | 어떤 숫자든 0~1로 눌러 주는 S자 함수 `1/(1+e⁻ᶻ)` | σ(0) = 0.5 |
| 임계값 (Threshold) | 확률을 "예/아니오"로 자르는 기준 | 0.5, 안전 분야는 0.3 |
| 결정 경계 (Decision Boundary) | 확률이 정확히 임계값이 되는 선. 이 선을 기준으로 양쪽이 다른 범주 | `w·x + b = 0` |
| 이진 교차 엔트로피 (BCE) | 분류용 손실. 정답 확률이 낮을수록 크게 벌줌 | `-[y·log p + (1-y)·log(1-p)]` |
| 소프트맥스 회귀 | 로지스틱 회귀를 다중 분류로 넓힌 것 (Day 008의 Softmax 사용) | 숫자 0~9 분류 |
| 선형 분리 가능 (Linearly Separable) | 직선(평면) 하나로 두 범주를 나눌 수 있는 데이터 | XOR은 불가능 |

## 3. 개념과 작동 원리

### 3-1. 왜 선형 회귀로 분류하면 안 될까?
```
 정답(0/1)
  1 ┤            ●  ●  ●  ●      ●  ← 멀리 떨어진 착용 데이터 하나
    │          ╱                      때문에 직선이 눕고
  0.5┤- - - - ╱- - - - - - - - -       경계가 오른쪽으로 밀려남
    │  ●  ● ╱                        → 착용인 사람도 미착용으로 판정!
  0 ┤●  ●  ╱
    └────────────────────────── x
 문제 ① 출력이 1보다 크거나 0보다 작게 나와 "확률"이 아님
 문제 ② 멀리 있는 점 하나에 경계가 크게 흔들림
```
→ 출력을 0~1로 가두고, 경계 근처에만 민감하게 반응하는 **시그모이드**를 씌웁니다.

### 3-2. 시그모이드 함수
```
 σ(z) = 1 / (1 + e⁻ᶻ)
```
| z (로짓) | -6 | -2 | -1 | 0 | 1 | 2 | 6 |
|---|---|---|---|---|---|---|---|
| σ(z) (확률) | 0.002 | 0.12 | 0.27 | **0.50** | 0.73 | 0.88 | 0.998 |

- z가 크면 1에, 작으면 0에 가까워지고 **절대 0이나 1을 넘지 않습니다**.
- z = 0일 때 정확히 0.5 → **`w·x + b = 0`인 곳이 결정 경계**입니다.
- 미분이 간단합니다: `σ'(z) = σ(z)·(1 - σ(z))`.

### 3-3. 결정 경계 — 입력이 2개면 "직선"이 경계
안전모 예시: 사람 머리 영역에서 두 가지 특징을 뽑았다고 합시다.
- `x₁` = 노란색 픽셀 비율 (0~1)
- `x₂` = 머리 윗부분의 둥근 윤곽 점수 (0~1)

```
 x₂ (둥근 윤곽)
  1.0 ┤   ○   ○       ●   ●  ●
      │ ○   ○   ○  ╲ ●   ●    ●       ● = 착용 (1)
      │   ○    ○    ╲   ●  ●          ○ = 미착용 (0)
  0.5 ┤ ○   ○   ○    ╲  ●   ●
      │   ○   ○    ○  ╲   ●   ●       ╲ = 결정 경계
      │ ○   ○   ○      ╲ ●  ●             w₁·x₁ + w₂·x₂ + b = 0
  0.0 ┤                 ╲
      └────────────────────────── x₁ (노란색 비율)
      0                0.5         1.0
  경계 오른쪽 위: z > 0 → 확률 > 0.5 → 착용
  경계 왼쪽 아래: z < 0 → 확률 < 0.5 → 미착용
```
> 로지스틱 회귀의 경계는 항상 **직선(평면)** 입니다. 경계가 곡선이어야 하는 데이터는 특성을 추가하거나 신경망을 써야 합니다.

### 3-4. 손실 함수 — 이진 교차 엔트로피 (BCE)
```
 BCE = -[ y·log(p) + (1-y)·log(1-p) ]       p = 모델이 말한 "1일 확률"

 정답 y = 1 일 때 → 손실 = -log(p)          정답 y = 0 일 때 → 손실 = -log(1-p)
```
| 정답 | 모델 확률 p | 손실 | 의미 |
|---|---|---|---|
| 1 (착용) | 0.95 | 0.05 | 자신 있게 맞힘 → 손실 거의 0 |
| 1 (착용) | 0.60 | 0.51 | 맞혔지만 애매함 |
| 1 (착용) | 0.10 | **2.30** | 자신 있게 틀림 → 큰 벌 |
| 0 (미착용) | 0.10 | 0.11 | 잘 맞힘 |

```
 손실
  4 ┤●
  3 ┤ ●                 정답이 1일 때 -log(p)
  2 ┤   ●               p가 0에 가까울수록(확신하고 틀릴수록)
  1 ┤      ●            손실이 폭발적으로 커짐
  0 ┤          ●  ●  ●  ●
    └──────────────────── p
     0.0   0.5      1.0
```
**왜 MSE를 안 쓰나?** 시그모이드 + MSE는 손실 그래프가 울퉁불퉁해져 경사하강이 중간에 멈추기 쉽고, 크게 틀렸을 때 기울기가 오히려 작아 학습이 느립니다. 시그모이드 + BCE는 매끈한 그릇 모양입니다.

### 3-5. 그래디언트 — 선형 회귀와 똑같은 모양!
시그모이드와 BCE를 함께 미분하면 신기하게도 깔끔해집니다.
```
 ∂L/∂w = mean( (p - y) · x )        ← 선형 회귀: mean( (ŷ - y) · x ) 와 같은 꼴
 ∂L/∂b = mean(  p - y )

 p - y = "예측 확률 - 정답"
   정답 1인데 p = 0.2 → p - y = -0.8 → w를 키워서 z를 올린다
   정답 0인데 p = 0.9 → p - y = +0.9 → w를 줄여서 z를 내린다
```

### 3-6. 임계값 바꾸기 (Day 006 연결)
| 임계값 | 착용으로 판정하는 기준 | 효과 |
|---|---|---|
| 0.5 (기본) | 확률 50% 이상 | 균형 |
| 0.8 (높임) | 아주 확실할 때만 "착용" | "미착용"을 더 많이 잡음 → **미착용에 대한 재현율↑**, 잘못된 경보↑ |
| 0.3 (낮춤) | 조금만 그럴듯해도 "착용" | 경보는 줄지만 미착용을 놓칠 위험↑ |

> 안전 현장에서는 "미착용을 놓치는 것"이 더 위험하므로, **착용으로 판정하는 임계값을 높게** 잡는 식으로 조정합니다. 모델은 그대로 두고 **숫자 하나만** 바꾸면 됩니다.

### 3-7. 다중 분류로 넓히기 — 소프트맥스 회귀
```
 이진:  z = w·x + b      →  Sigmoid  →  P(착용)
 다중:  z₁ = w₁·x + b₁   ┐
        z₂ = w₂·x + b₂   ├─▶ Softmax ─▶ [P(착용), P(미착용), P(사람 아님)]  합 = 1
        z₃ = w₃·x + b₃   ┘
 손실:  교차 엔트로피 = -log P(정답 클래스)
```
클래스마다 가중치 한 세트씩, 즉 **가중치 행렬 W** 가 됩니다 (Day 007의 행렬 곱).

## 4. 구조 — 로지스틱 회귀 = 시그모이드 뉴런 하나
```
   입력           가중치        합산           활성화          출력
   x₁ ───── w₁ ──╮
   x₂ ───── w₂ ──┼──▶ z = Σwᵢxᵢ + b ──▶ σ(z) ──▶ p = P(y=1) ──▶ p ≥ 0.5 ? 1 : 0
   x₃ ───── w₃ ──╯

 YOLO 같은 딥러닝 분류기의 마지막 단계도 같음:
   [사진] → (수많은 층이 특징 x를 자동 추출) → 마지막 층: z = W·x + b → Sigmoid/Softmax → 클래스 확률
           └──── 딥러닝이 "좋은 특징"을 스스로 만듦 ────┘     └──── 여기가 로지스틱 회귀 ────┘
```

| 기준 모델 | 복잡한 분류 모델 전에 "로지스틱 회귀보다 나은가?" 확인 |
| 해석 | 가중치 w의 부호·크기로 "어떤 특징이 결과를 키우는지" 바로 읽을 수 있음 |

### 6-1. 시그모이드와 BCE 손실 직접 확인
```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

print("z     σ(z)   막대")
for z in [-6, -2, -1, 0, 1, 2, 6]:
    p = sigmoid(z)
    print(f"{z:>3}  {p:6.3f}  {'█' * round(p * 30)}")

def bce(y, p):
    return -(y * np.log(p) + (1 - y) * np.log(1 - p))

print("\n정답  확률   손실")
for y, p in [(1, 0.95), (1, 0.60), (1, 0.10), (0, 0.10)]:
    print(f" {y}    {p:.2f}  {bce(y, p):5.2f}")
```

### 6-2. 경사하강법으로 직접 학습하고 결정 경계 그리기
```python
import numpy as np
rng = np.random.default_rng(1)

# 가짜 데이터: [노란색 비율, 둥근 윤곽 점수]
on  = rng.normal([0.7, 0.7], 0.12, size=(30, 2))     # 착용(1)
off = rng.normal([0.3, 0.35], 0.12, size=(30, 2))    # 미착용(0)
X = np.clip(np.vstack([on, off]), 0, 1)
y = np.array([1] * 30 + [0] * 30)

sigmoid = lambda z: 1 / (1 + np.exp(-z))
w, b, lr = np.zeros(2), 0.0, 1.0
for epoch in range(1001):
    p = sigmoid(X @ w + b)                            # ① 확률 예측
    loss = -np.mean(y * np.log(p + 1e-9) + (1 - y) * np.log(1 - p + 1e-9))  # ② BCE
    w -= lr * (X.T @ (p - y)) / len(y)                # ③ 그래디언트: mean((p-y)·x)
    b -= lr * np.mean(p - y)
    if epoch in (0, 10, 100, 1000):
        acc = np.mean((p >= 0.5) == y)
        print(f"epoch {epoch:>4}  손실 {loss:.3f}  정확도 {acc:.0%}")
print(f"w = [{w[0]:.2f}, {w[1]:.2f}], b = {b:.2f}")

# 글자 그림: ●착용 ○미착용, 배경 .은 '착용'으로 판정되는 영역
H, W = 12, 36
grid = [[" "] * W for _ in range(H)]
for r in range(H):
    for c in range(W):
        x1, x2 = c / (W - 1), 1 - r / (H - 1)
        if sigmoid(w[0] * x1 + w[1] * x2 + b) >= 0.5:
            grid[r][c] = "."
for (x1, x2), label in zip(X, y):
    grid[round((1 - x2) * (H - 1))][round(x1 * (W - 1))] = "●" if label else "○"
print("\nx₂(윤곽) ↑    (.) = 모델이 '착용'이라고 판정하는 영역")
for line in grid:
    print("  │" + "".join(line))
print("  └" + "─" * W + "→ x₁(노란색 비율)")
```

### 6-3. scikit-learn으로 학습하고, 확률과 임계값 바꿔 보기
```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import confusion_matrix

rng = np.random.default_rng(1)
on  = rng.normal([0.7, 0.7], 0.12, size=(30, 2))
off = rng.normal([0.3, 0.35], 0.12, size=(30, 2))
X = np.clip(np.vstack([on, off]), 0, 1)
y = np.array([1] * 30 + [0] * 30)

model = LogisticRegression().fit(X, y)
print("새 사람 3명의 착용 확률")
for name, feat in [("노란색 많고 둥근", [0.8, 0.75]),
                   ("애매함",          [0.5, 0.5]),
                   ("노란색 거의 없음", [0.1, 0.3])]:
    p = model.predict_proba([feat])[0, 1]
    print(f"  {name:<10} → {p:.2f}  {'█' * round(p * 20)}")

proba = model.predict_proba(X)[:, 1]
print("\n임계값   착용 판정   미착용을 착용으로 잘못 판정(FP)   착용을 놓침(FN)")
for t in [0.3, 0.5, 0.8]:
    tn, fp, fn, tp = confusion_matrix(y, proba >= t).ravel()
    print(f"  {t:.1f}      {tp + fp:>2}명            {fp:>2}명                       {fn:>2}명")
```

```
  0.8       7명             0명                       23명
```
임계값을 **높이면** "착용" 판정이 깐깐해져 미착용을 착용으로 잘못 넘기는 경우(FP)가 줄고, 대신 실제 착용자를 놓치는 경우(FN)가 늘어납니다. 현장에서 무엇이 더 위험한지에 따라 고릅니다 (Day 006).
