## 1. 한 줄 요약
**결정 트리(Decision Tree)** 는 "온도가 60도보다 높은가?" 같은 **예/아니오 질문을 차례로 이어 붙여** 답을 찾는 모델입니다. 스무고개와 똑같습니다. 어떤 질문을 먼저 할지는 **지니 불순도(Gini)** 나 **엔트로피** 가 가장 많이 줄어드는 질문을 골라 자동으로 정합니다. 직선 하나로 나눌 수 없는 데이터(Day 010의 한계)도 나눌 수 있고, 만들어진 규칙을 사람이 그대로 읽을 수 있다는 것이 큰 장점입니다. 다만 너무 깊게 키우면 과적합되기 쉽습니다.

```
                    ┌──────────────────┐
                    │ 진동 > 4.5 mm/s ? │  ← 뿌리 노드 (가장 좋은 첫 질문)
                    └────────┬─────────┘
                  아니오 ┌────┴────┐ 예
                ┌───────▼──┐   ┌──▼─────────┐
                │ 온도 > 70?│   │ 🔴 불량     │  ← 잎 노드 (최종 답)
                └────┬─────┘   └────────────┘
            아니오 ┌──┴──┐ 예
          ┌───────▼┐   ┌▼────────┐
          │ 🟢 정상 │   │ 🔴 불량  │
          └────────┘   └─────────┘
```

## 2. 핵심 용어
| 용어 | 뜻 | 예시 |
|---|---|---|
| 노드 (Node) | 나무의 마디. 질문이 있거나 답이 있는 곳 | "온도 > 70?" |
| 뿌리 노드 (Root) | 맨 위 첫 번째 질문 | 가장 정보가 많은 질문 |
| 내부 노드 (Internal) | 중간 질문 | |
| 잎 노드 (Leaf) | 더 이상 나누지 않는 끝. 최종 예측값 | "불량" |
| 분할 (Split) | 질문 하나로 데이터를 두 그룹으로 나누는 것 | 진동 4.5 기준 |
| 깊이 (Depth) | 뿌리에서 가장 먼 잎까지 질문 수 | 깊이 3 |
| 불순도 (Impurity) | 한 그룹에 여러 클래스가 섞인 정도 | 정상 5 + 불량 5 = 가장 섞임 |
| 지니 불순도 (Gini) | `1 - Σ pᵢ²`. 0이면 순수, 이진 분류 최대 0.5 | |
| 엔트로피 (Entropy) | `-Σ pᵢ·log₂pᵢ`. 0이면 순수, 이진 분류 최대 1 | |
| 정보 이득 (Information Gain) | 분할 전 불순도 - 분할 후 (가중 평균) 불순도 | 클수록 좋은 질문 |
| 가지치기 (Pruning) | 과적합을 막으려고 트리를 덜 키우거나 잘라내는 것 | `max_depth=3` |
| 특성 중요도 (Feature Importance) | 각 특성이 불순도를 얼마나 줄였는지의 합 | 진동 0.7, 온도 0.3 |

## 3. 개념과 작동 원리

### 3-1. 스무고개처럼 질문하기
사람은 이미 결정 트리로 판단합니다.
```
 "오늘 우산 챙길까?"
     하늘이 흐린가? ── 아니오 ──▶ 안 챙김
         │ 예
     강수확률 > 60%? ── 아니오 ──▶ 접이식만
         │ 예
       챙김 ☂️
```
결정 트리는 이런 **질문 순서와 기준값(60%)을 데이터로부터 자동으로** 찾아냅니다.

### 3-2. 좋은 질문이란? — 불순도가 많이 줄어드는 질문
부품 10개(정상 5, 불량 5)를 두 가지 질문으로 나눠 봅니다.
```
                   분할 전: 🟢🟢🟢🟢🟢🔴🔴🔴🔴🔴   (완전히 섞임)

 질문 A: "온도 > 70?"                       질문 B: "진동 > 4.5?"
   아니오: 🟢🟢🟢🔴🔴  예: 🟢🟢🔴🔴🔴        아니오: 🟢🟢🟢🟢🟢🔴  예: 🔴🔴🔴🔴
          (여전히 섞임)                            (거의 순수)        (완전 순수)
   → 별로 도움이 안 됨                         → 아주 좋은 질문! 뿌리 노드로 선택
```

### 3-3. 지니 불순도 손으로 계산하기
`Gini = 1 - (정상 비율)² - (불량 비율)²`

| 그룹 | 구성 | 계산 | Gini |
|---|---|---|---|
| 분할 전 | 🟢5 🔴5 | 1 - 0.5² - 0.5² | **0.500** |
| A 아니오 | 🟢3 🔴2 | 1 - 0.6² - 0.4² | 0.480 |
| A 예 | 🟢2 🔴3 | 1 - 0.4² - 0.6² | 0.480 |
| B 아니오 | 🟢5 🔴1 | 1 - (5/6)² - (1/6)² | 0.278 |
| B 예 | 🔴4 | 1 - 0² - 1² | **0.000** (순수) |

분할 후 불순도는 그룹 크기로 **가중 평균**합니다.
```
 질문 A: (5/10)·0.480 + (5/10)·0.480 = 0.480   → 정보 이득 = 0.500 - 0.480 = 0.020
 질문 B: (6/10)·0.278 + (4/10)·0.000 = 0.167   → 정보 이득 = 0.500 - 0.167 = 0.333  ✅
```
> 트리는 **모든 특성 × 모든 기준값**을 다 시험해 보고 정보 이득이 가장 큰 질문을 고릅니다. 그런 다음 나뉜 각 그룹에서 같은 일을 **반복**(재귀)합니다.

### 3-4. 지니 vs 엔트로피
```
 불순도
  1.0 ┤             ╭───╮            ── 엔트로피 (최대 1.0)
      │          ╭──╯   ╰──╮
  0.5 ┤       ╭──┼──━━━━━──┼──╮      ━━ 지니 (최대 0.5)
      │    ╭━━╯  ┃       ┃  ╰━━╮
  0.0 ┤━━━━╯                    ╰━━━━
      └──────────────┼───────────── 불량 비율
      0             0.5            1.0
```
| | 지니 | 엔트로피 |
|---|---|---|
| 공식 | `1 - Σp²` | `-Σp·log₂p` |
| 계산 | 빠름 (로그 없음) | 조금 느림 |
| 결과 | 거의 비슷한 트리 | 거의 비슷한 트리 |
| scikit-learn 기본값 | ✅ `criterion="gini"` | `criterion="entropy"` |

### 3-5. 결정 경계 — 직선이 아니라 "계단"
결정 트리는 한 번에 **특성 하나**만 보고 자르므로, 축에 평행한 선으로 공간을 잘게 나눕니다.
```
 로지스틱 회귀 (Day 010)           결정 트리
  x₂                               x₂
   │ ○ ○ ╲ ● ●                      │ ○ ○ ┃ ● ●
   │ ○ ○  ╲ ● ●                     │ ○ ○ ┃ ● ●
   │ ○ ○ ○ ╲ ●                      │━━━━━┛ ● ●
   │ ○ ○ ○ ○╲ ●                     │ ○ ○ ○ ┃ ●
   └────────────── x₁               └───────┸────── x₁
   비스듬한 직선 하나                  축에 평행한 선을 여러 번 → 계단 모양
```
**XOR처럼 직선으로 절대 못 나누는 데이터**도 나눌 수 있습니다.
```
  x₂                                    트리:  x₁ > 0.5?
   │ ●  ●  ┃  ○  ○                          ├ 아니오 → x₂ > 0.5? → 예: ● / 아니오: ○
   │ ●  ●  ┃  ○  ○                          └ 예    → x₂ > 0.5? → 예: ○ / 아니오: ●
   │━━━━━━━╋━━━━━━━
   │ ○  ○  ┃  ●  ●       직선 하나로는 ●와 ○를 나눌 방법이 없지만
   │ ○  ○  ┃  ●  ●       질문 2~3단계면 나뉨 (6-2 코드에서 확인)
   └──────────────── x₁
```

### 3-6. 과적합과 가지치기
제한 없이 키우면 트리는 **훈련 데이터 하나하나에 맞는 잎**을 만들어 버립니다 (Day 005).
| 설정 | 의미 | 효과 |
|---|---|---|
| `max_depth` | 최대 깊이 제한 | 가장 많이 쓰는 가지치기 |
| `min_samples_split` | 이 개수보다 적으면 더 나누지 않음 | 잡음에 반응 줄임 |
| `min_samples_leaf` | 잎에 최소 이만큼은 남겨야 함 | 극단적인 잎 방지 |
| `ccp_alpha` | 복잡도 대가를 두고 다 키운 뒤 잘라냄 (사후 가지치기) | |

```
 정확도
 100%┤ ●━━●━━●━━●━━●━━●  훈련 (깊어질수록 100%로)
     │      ○━━○
  85%┤   ○╱      ╲○━━○━━○  검증 (어느 깊이부터 떨어짐 = 과적합)
     │ ○
     └──┬──┬──┬──┬──┬──┬── max_depth
        1  2  3  4  5  ∞
              ↑ 여기가 적당
```

### 3-7. 회귀 트리 — 숫자도 예측 가능
잎에 **클래스 대신 평균값**을 두면 숫자를 예측합니다. 분할 기준은 불순도 대신 **MSE 감소량**을 씁니다. 예측 곡선이 계단 모양이 됩니다.

### 3-8. 장단점
| 장점 | 단점 |
|---|---|
| 규칙을 사람이 그대로 읽을 수 있음 (설명 가능) | 깊으면 과적합이 매우 쉬움 |
| 특성 스케일링 불필요 (기준값으로만 자르므로) | 데이터가 조금만 바뀌어도 트리 모양이 크게 바뀜 (불안정) |
| 직선으로 못 나누는 관계도 학습 | 축에 평행한 계단 경계라 비스듬한 경계는 비효율적 |
| 수치·범주 특성을 함께 다루기 쉬움 | 단독 성능은 보통 앙상블보다 낮음 |

> 단점을 보완하려고 트리를 **수백 개 모아서** 쓰는 것이 **랜덤 포레스트·부스팅** 입니다 (Day 012).

## 4. 구조 — 학습 알고리즘 (CART)
```
 build_tree(데이터):
   ① 멈출 조건? (모두 같은 클래스 / 최대 깊이 도달 / 데이터가 너무 적음)
        └ 예 → 잎 노드 만들기 (다수결 클래스 또는 평균값) → 끝
   ② 모든 특성 j, 모든 기준값 t 에 대해
        "x_j ≤ t" 로 나눴을 때의 정보 이득 계산
   ③ 정보 이득이 가장 큰 (j, t) 선택 → 내부 노드
   ④ 왼쪽 데이터로 build_tree(), 오른쪽 데이터로 build_tree()   ← 재귀

 예측: 새 데이터를 뿌리부터 질문에 답하며 내려가 도착한 잎의 값을 출력
       → 질문 수 = 깊이 만큼이라 예측이 매우 빠름
```

## 6. 코드로 보기

### 6-1. 지니 불순도와 정보 이득 직접 계산
```python
def gini(counts):
    n = sum(counts)
    return 1 - sum((c / n) ** 2 for c in counts)

def weighted_gini(groups):
    total = sum(sum(g) for g in groups)
    return sum(sum(g) / total * gini(g) for g in groups)

before = gini([5, 5])
print(f"분할 전 Gini = {before:.3f}")
for name, groups in [("A: 온도 > 70 ", [[3, 2], [2, 3]]),
                     ("B: 진동 > 4.5", [[5, 1], [0, 4]])]:
    after = weighted_gini(groups)
    gain = before - after
    print(f"{name}  분할 후 {after:.3f}  정보 이득 {gain:.3f}  {'█' * round(gain * 60)}")
```
실행 결과
```

A: 온도 > 70   분할 후 0.480  정보 이득 0.020  █
B: 진동 > 4.5  분할 후 0.167  정보 이득 0.333  ████████████████████
```

### 6-2. 직선으로 못 나누는 XOR 데이터 — 로지스틱 회귀 vs 결정 트리
```python
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier

rng = np.random.default_rng(0)
X = rng.random((200, 2))
y = ((X[:, 0] > 0.5) ^ (X[:, 1] > 0.5)).astype(int)   # XOR: 대각선 칸끼리 같은 클래스

for name, model in [("로지스틱 회귀", LogisticRegression()),
                    ("결정 트리   ", DecisionTreeClassifier(max_depth=3, random_state=0))]:
    model.fit(X, y)
    print(f"{name} 정확도: {model.score(X, y):.0%}")
    H, W = 8, 24
    for r in range(H):
        row = ""
        for c in range(W):
            p = model.predict([[c / (W - 1), 1 - r / (H - 1)]])[0]
            row += "●" if p else "·"
        print("   " + row)
    print()
```

로지스틱 회귀는 직선 하나밖에 못 그어서 일부만 맞히지만, 결정 트리는 네 칸을 정확히 나눕니다. 참고로 `max_depth=2`로 바꾸면 88%에 그칩니다. XOR은 첫 질문 하나만으로는 불순도가 거의 줄지 않아서, 탐욕적으로(그 순간 최선만 보고) 고른 첫 질문이 0.5가 아닌 곳을 자르기 때문입니다. 한 단계 더 허용하면 바로잡힙니다.

### 6-3. 부품 불량 판정 트리 학습 — 규칙 읽기, 깊이별 과적합, 특성 중요도
```python
import numpy as np
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(42)
n = 400
temp = rng.normal(65, 10, n)        # 온도(℃)
vib  = rng.normal(4.0, 1.2, n)      # 진동(mm/s)
noise = rng.normal(0, 1, n)         # 아무 상관 없는 센서
defect = ((vib > 4.8) | ((temp > 75) & (vib > 3.5))).astype(int)
flip = rng.random(n) < 0.08         # 라벨 노이즈 8%
defect[flip] = 1 - defect[flip]
X = np.column_stack([temp, vib, noise])
names = ["온도", "진동", "잡음센서"]
X_tr, X_va, y_tr, y_va = train_test_split(X, defect, test_size=0.3, random_state=0)

# (1) 깊이 2 트리의 규칙을 사람이 읽을 수 있는 형태로
tree = DecisionTreeClassifier(max_depth=2, min_samples_leaf=10, random_state=0).fit(X_tr, y_tr)
print(export_text(tree, feature_names=names, class_names=["정상", "불량"]))

# (2) 깊이에 따른 훈련/검증 정확도 → 과적합 확인
print("max_depth  훈련    검증")
for d in [1, 2, 3, 5, 8, None]:
    m = DecisionTreeClassifier(max_depth=d, random_state=0).fit(X_tr, y_tr)
    print(f"  {str(d):<6}  {m.score(X_tr, y_tr):.0%}   {m.score(X_va, y_va):.0%}  {'█' * round(m.score(X_va, y_va) * 30)}")

# (3) 특성 중요도
best = DecisionTreeClassifier(max_depth=3, random_state=0).fit(X_tr, y_tr)
print("\n특성 중요도")
for name, imp in zip(names, best.feature_importances_):
    print(f"  {name:<5} {imp:.2f}  {'█' * round(imp * 30)}")
```
