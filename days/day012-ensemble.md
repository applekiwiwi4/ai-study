# Day 012 — 앙상블: 랜덤 포레스트, 부스팅(XGBoost, LightGBM)

> 📅 2026-11-22 · 2부. 고전 머신러닝 · ⏱ 예상 학습 시간 40~50분

## 1. 한 줄 요약
**앙상블(Ensemble)** 은 여러 모델의 예측을 모아 하나의 더 좋은 답을 만드는 방법입니다. "전문가 한 명보다 여러 명의 투표가 낫다"는 원리입니다. 결정 트리(Day 011)를 재료로 쓰는 두 가지 대표 방식이 있습니다. **랜덤 포레스트**는 서로 조금씩 다른 트리 수백 개를 **동시에(병렬)** 키워 **투표**하고, **부스팅**은 트리를 **하나씩 차례로(순차)** 만들면서 앞 트리가 **틀린 부분을 다음 트리가 고치게** 합니다. XGBoost와 LightGBM은 부스팅을 빠르고 강하게 만든 라이브러리이며, 표 형식 데이터에서는 지금도 가장 강력한 방법으로 꼽힙니다.

```
 배깅 / 랜덤 포레스트 (병렬)                    부스팅 (순차)
 ┌──────── 데이터 ────────┐                  데이터 ─▶ 🌳₁ ─▶ 남은 오차 ─▶ 🌳₂ ─▶ 남은 오차 ─▶ 🌳₃ ...
 │무작위 뽑기 │무작위 뽑기 │ ...                         │              │              │
 🌳₁        🌳₂        🌳₃                            └──── 작은 수정을 계속 더함 ────┘
  │          │          │                       최종 = 🌳₁ + η·🌳₂ + η·🌳₃ + ...
  └──── 투표(다수결) / 평균 ────┘
  "독립적인 여러 의견을 모은다"                      "앞사람의 실수를 다음 사람이 보완한다"
  → 분산(흔들림) ↓, 과적합에 강함                    → 편향(오차) ↓, 정확도 최상급
```

## 2. 핵심 용어
| 용어 | 뜻 | 예시 |
|---|---|---|
| 앙상블 (Ensemble) | 여러 모델의 예측을 결합하는 방법 | 트리 300개 투표 |
| 약한 학습기 (Weak Learner) | 혼자서는 성능이 그저 그런 단순한 모델 | 깊이 1~3의 얕은 트리 |
| 배깅 (Bagging) | Bootstrap AGGregatING. 데이터를 복원 추출해 여러 모델을 만들고 평균·투표 | |
| 부트스트랩 (Bootstrap) | 원본에서 **같은 개수만큼 중복을 허용해** 무작위로 뽑은 샘플 | 1,2,2,5,7 … |
| OOB (Out-Of-Bag) | 부트스트랩에서 뽑히지 않은 약 37%의 데이터. 공짜 검증 세트로 씀 | `oob_score=True` |
| 랜덤 포레스트 (Random Forest) | 배깅 + 분할할 때마다 **특성도 일부만 무작위로** 고려 | `max_features="sqrt"` |
| 부스팅 (Boosting) | 모델을 순서대로 만들며 이전 모델의 오차를 줄여 가는 방법 | |
| 그래디언트 부스팅 (Gradient Boosting) | 각 트리가 **손실의 그래디언트(잔차)** 를 예측하도록 학습 | Day 008·009 연결 |
| 학습률 / 수축 (Learning Rate, η) | 새 트리의 예측을 얼마나 반영할지 (0.01~0.3) | `learning_rate=0.1` |
| XGBoost | 규제·병렬 처리·결측치 처리를 더한 그래디언트 부스팅 라이브러리 | 대회 단골 우승 |
| LightGBM | 히스토그램 분할 + 잎 우선 성장으로 더 빠른 부스팅 라이브러리 | 대용량 데이터 |
| 조기 종료 (Early Stopping) | 검증 손실이 더 이상 줄지 않으면 트리 추가를 멈춤 | Day 005 연결 |

## 3. 개념과 작동 원리

### 3-1. 왜 여러 모델을 모으면 좋아질까?
정확도 70%인 모델 하나와, 각각 70%인데 **서로 독립적으로 틀리는** 모델 5개의 다수결을 비교해 봅니다.
```
 5개 중 3개 이상이 맞으면 다수결이 정답
 P(3개 이상 맞음) = C(5,3)·0.7³·0.3² + C(5,4)·0.7⁴·0.3 + 0.7⁵
                  = 0.309 + 0.360 + 0.168 = 0.837      ← 70% → 약 84%로 상승!

 모델 수   1     5     11    25    101
 다수결   70%   84%   92%   98%   ≈100%  (모두 독립일 때의 이론값, 6-1 코드에서 확인)
```
> 핵심 조건은 **"서로 다르게 틀려야 한다"** 는 것입니다. 똑같은 트리 100개를 모으면 하나와 똑같습니다. 그래서 랜덤 포레스트는 일부러 **무작위성**을 넣어 트리들을 서로 다르게 만듭니다.

### 3-2. 배깅 — 부트스트랩으로 다양한 트리 만들기
```
 원본 데이터: [A B C D E F G H]   (8개)

 부트스트랩 1: [A A C D F F G H]  → 🌳₁ 학습     OOB: B, E
 부트스트랩 2: [B C C D E G H H]  → 🌳₂ 학습     OOB: A, F
 부트스트랩 3: [A B D D E E F G]  → 🌳₃ 학습     OOB: C, H
                ↑ 중복 허용, 원본과 같은 개수

 예측: 분류 → 다수결 투표 / 회귀 → 평균
```
- 각 트리는 조금씩 다른 데이터를 보므로 서로 다른 모양이 됩니다.
- 한 샘플이 부트스트랩에 한 번도 안 뽑힐 확률은 `(1 - 1/n)ⁿ ≈ 0.368` → 약 37%는 OOB로 남아 **따로 검증 세트를 떼지 않아도** 성능을 추정할 수 있습니다.

### 3-3. 랜덤 포레스트 = 배깅 + 특성 무작위 선택
배깅만 하면 강한 특성(예: 진동) 하나가 모든 트리의 뿌리를 차지해 트리들이 비슷해집니다. 랜덤 포레스트는 **분할할 때마다 특성 중 일부(보통 √특성 수)만** 후보로 봅니다.
```
 특성: [온도, 진동, 압력, 전류, 습도, 소음, 속도, 무게, 시간]   (9개, √9 = 3)

 🌳₁ 뿌리 후보: [압력, 진동, 습도]  → 진동 선택
 🌳₂ 뿌리 후보: [온도, 소음, 무게]  → 온도 선택   ← 진동이 없으니 다른 길을 탐색
 🌳₃ 뿌리 후보: [전류, 시간, 진동]  → 진동 선택
 → 트리들이 더 다양해짐 → 투표 효과가 커짐
```

### 3-4. 부스팅 — 틀린 부분을 다음 트리가 고친다
그래디언트 부스팅으로 집값을 예측하는 과정입니다 (회귀, 손실 = MSE).
```
 실제 집값 y            :  [ 3억,   5억,   9억 ]
 ① 시작 예측 F₀ = 평균    :  [5.67,  5.67,  5.67]
    잔차 r₁ = y - F₀      :  [-2.67, -0.67, +3.33]   ← 🌳₁이 이 "잔차"를 예측하도록 학습
 ② F₁ = F₀ + η·🌳₁        (η = 0.5, 🌳₁이 잔차를 정확히 맞혔다고 가정)
         = [4.33,  5.33,  7.33]
    잔차 r₂ = y - F₁      :  [-1.33, -0.33, +1.67]   ← 🌳₂가 남은 잔차를 학습
 ③ F₂ = F₁ + η·🌳₂        = [3.67,  5.17,  8.17]
    ...  반복할수록 잔차 → 0
```
> **잔차 = MSE 손실의 음의 그래디언트**입니다 (`-∂L/∂F ∝ y - F`). 즉 부스팅은 "가중치"가 아니라 "예측값 자체"에 대해 **경사하강법**을 하는 것과 같습니다. 그래서 이름이 **그래디언트** 부스팅입니다.

**학습률 η가 작을수록** 한 번에 조금씩 고치므로 트리가 더 많이 필요하지만 일반화가 좋아집니다 (Day 004와 같은 원리).

### 3-5. XGBoost와 LightGBM은 뭐가 다른가
| | 기본 그래디언트 부스팅 | XGBoost | LightGBM |
|---|---|---|---|
| 분할 탐색 | 모든 값을 정렬해 탐색 | 정렬 + 근사 분위수 | **히스토그램**(값을 구간으로 묶음) → 매우 빠름 |
| 트리 성장 | 층 단위 (level-wise) | 층 단위 | **잎 우선** (leaf-wise): 손실을 가장 많이 줄이는 잎부터 |
| 규제 | 거의 없음 | L1/L2 규제 내장 (Day 005) | L1/L2 규제 |
| 결측치 | 직접 처리 필요 | 자동으로 최적 방향 학습 | 자동 처리 |
| 강점 | 개념 학습용 | 안정적, 자료 많음 | 대용량에서 속도 |

```
 층 단위 (XGBoost)               잎 우선 (LightGBM)
        ●                              ●
      ╱   ╲                          ╱   ╲
     ●     ●     ← 한 층씩 고르게    ●     ○     ← 가장 이득 큰 잎만 계속 깊게
    ╱ ╲   ╱ ╲                      ╱ ╲
   ○   ○ ○   ○                    ●   ○
                                 ╱ ╲
                                ○   ○
```
> scikit-learn의 `HistGradientBoostingClassifier`도 LightGBM에서 영감을 받은 히스토그램 방식이라, 추가 설치 없이 비슷한 속도를 냅니다.

### 3-6. 랜덤 포레스트 vs 부스팅
| | 랜덤 포레스트 | 그래디언트 부스팅 (XGBoost·LightGBM) |
|---|---|---|
| 트리 만드는 방식 | 독립적으로 동시에 | 이전 트리 결과에 이어서 순차적으로 |
| 개별 트리 | 깊고 큰 트리 | 얕은 트리 (깊이 3~8) |
| 주로 줄이는 것 | 분산 (과적합) | 편향 (오차) |
| 트리를 많이 넣으면 | 과적합 거의 없음, 성능 수렴 | 너무 많으면 과적합 → 조기 종료 필요 |
| 하이퍼파라미터 | 적고 튜닝 쉬움 | 많고 튜닝이 성능을 크게 좌우 |
| 성능 | 좋음, 기본값으로도 안정적 | 튜닝하면 보통 최상 |
| 추천 상황 | 빠르게 튼튼한 기준 모델이 필요할 때 | 성능을 끝까지 끌어올리고 싶을 때 |

## 4. 구조 — 학습과 예측 흐름
```
 [랜덤 포레스트]
 for b = 1..B (예: 300):
     부트스트랩 샘플 뽑기
     트리 학습 (분할마다 특성 √p개만 후보)
 예측: 모든 트리의 다수결(분류) / 평균(회귀)

 [그래디언트 부스팅]
 F₀(x) = 상수 (회귀: 평균, 분류: 로그 오즈)
 for m = 1..M:
     rᵢ = -∂L(yᵢ, F(xᵢ)) / ∂F          ← 잔차(음의 그래디언트) 계산
     얕은 트리 hₘ 를 (xᵢ, rᵢ)에 맞춰 학습
     Fₘ(x) = Fₘ₋₁(x) + η · hₘ(x)        ← 조금씩 더하기
     검증 손실이 안 줄면 멈춤 (조기 종료)
 예측: F_M(x)  (분류는 Sigmoid/Softmax로 확률 변환, Day 010)
```

### 6-1. 다수결의 힘 — 독립 모델을 모으면 정확도가 오른다
```python
from math import comb

def majority_accuracy(p, n):
    """정확도 p인 독립 모델 n개의 다수결 정확도"""
    return sum(comb(n, k) * p**k * (1 - p)**(n - k) for k in range(n // 2 + 1, n + 1))

print("모델 수   다수결 정확도")
for n in [1, 5, 11, 25, 101]:
    acc = majority_accuracy(0.7, n)
    print(f"  {n:>3}      {acc:6.1%}  {'█' * round(acc * 40)}")
```

### 6-2. 트리 1개 vs 랜덤 포레스트 vs 부스팅 비교 (부품 불량 예측)
```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, HistGradientBoostingClassifier
from xgboost import XGBClassifier
from lightgbm import LGBMClassifier

# 센서 20개, 그중 6개만 실제로 불량과 관련, 라벨 노이즈 5%
X, y = make_classification(n_samples=3000, n_features=20, n_informative=6,
                           n_redundant=4, flip_y=0.05, random_state=7)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)

models = {
    "결정 트리 1개      ": DecisionTreeClassifier(random_state=0),
    "랜덤 포레스트 300  ": RandomForestClassifier(n_estimators=300, oob_score=True, random_state=0, n_jobs=-1),
    "HistGradientBoost ": HistGradientBoostingClassifier(random_state=0),
    "XGBoost           ": XGBClassifier(n_estimators=300, learning_rate=0.1, max_depth=4, random_state=0, verbosity=0),
    "LightGBM          ": LGBMClassifier(n_estimators=300, learning_rate=0.1, num_leaves=15, random_state=0, verbose=-1),
}
print("모델                 훈련    테스트")
for name, m in models.items():
    m.fit(X_tr, y_tr)
    tr, te = m.score(X_tr, y_tr), m.score(X_te, y_te)
    print(f"{name}  {tr:.1%}  {te:.1%}  {'█' * round((te - 0.7) * 100)}")

rf = models["랜덤 포레스트 300  "]
print(f"\n랜덤 포레스트 OOB 점수 (검증 세트 없이 추정): {rf.oob_score_:.1%}")
```
실행 결과
```
모델                 훈련    테스트
결정 트리 1개        100.0%  79.8%  ██████████
랜덤 포레스트 300    100.0%  87.6%  ██████████████████
HistGradientBoost   100.0%  86.4%  ████████████████
XGBoost             100.0%  86.8%  █████████████████
LightGBM            100.0%  85.9%  ████████████████

랜덤 포레스트 OOB 점수 (검증 세트 없이 추정): 88.5%
```
- 트리 1개는 훈련 100%인데 테스트가 크게 낮습니다 (과적합, Day 011).
- 랜덤 포레스트와 부스팅 계열은 테스트 정확도가 확실히 높습니다. 막대 길이는 70%를 넘는 부분만 그린 것입니다.
- OOB 점수가 실제 테스트 점수와 비슷하게 나와, 따로 떼어 둔 데이터 없이도 성능을 가늠할 수 있습니다.

### 6-3. 트리 개수에 따른 변화와 특성 중요도
```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier

X, y = make_classification(n_samples=3000, n_features=20, n_informative=6,
                           n_redundant=4, flip_y=0.05, shuffle=False, random_state=7)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, test_size=0.3, random_state=0)

# (1) 부스팅: 트리를 하나씩 더할 때마다 테스트 정확도 (staged_predict)
gb = GradientBoostingClassifier(n_estimators=300, learning_rate=0.1, max_depth=3, random_state=0)
gb.fit(X_tr, y_tr)
staged = [np.mean(p == y_te) for p in gb.staged_predict(X_te)]
print("부스팅 트리 수   테스트 정확도")
for k in [1, 5, 20, 50, 100, 200, 300]:
    print(f"   {k:>3}          {staged[k-1]:.1%}  {'█' * round((staged[k-1] - 0.6) * 100)}")
best = int(np.argmax(staged)) + 1
print(f"   → 가장 좋았던 트리 수: {best}개 ({staged[best-1]:.1%})")

# (2) 랜덤 포레스트 특성 중요도 (shuffle=False라 0~5번이 실제 정보 특성, 6~9번은 그 조합)
rf = RandomForestClassifier(n_estimators=300, random_state=0, n_jobs=-1).fit(X_tr, y_tr)
order = np.argsort(rf.feature_importances_)[::-1]
print("\n특성 중요도 상위 10개 (센서 번호)")
for i in order[:10]:
    tag = "정보" if i < 6 else ("조합" if i < 10 else "잡음")
    print(f"  센서{i:>2} [{tag}] {rf.feature_importances_[i]:.3f}  {'█' * round(rf.feature_importances_[i] * 200)}")
```
